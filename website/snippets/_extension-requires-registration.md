:::info Использует вашу учетную запись <Constant name="dbt_platform" />
Эта функция может читать данные из вашей учетной записи <Constant name="dbt_platform" />. [Войдите в систему](/docs/sign-in-dbt-extension), чтобы расширение dbt для VS Code могло получить к ней доступ.

Аутентификация выполняется с помощью [`dbt login`](/reference/commands/login?version=2.0), поэтому состояние входа в систему общее для CLI, расширения dbt для VS Code и <Constant name="copilot"/>.
