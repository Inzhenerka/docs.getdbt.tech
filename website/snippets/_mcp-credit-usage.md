:::info Удалённый MCP не требует функций ИИ

Для использования удалённого MCP не требуется включать [функции ИИ](/docs/platform/manage-dbt-ai). Если администратор отключит функции ИИ, [`text_to_sql`](/docs/dbt-ai/mcp-available-tools#tools-that-require-ai-features) будет единственным скрытым инструментом, а все остальные инструменты продолжат работать.

`text_to_sql` — также единственный инструмент, который расходует выделенный вам лимит действий dbt Copilot. Другие инструменты MCP его не расходуют.

Если в вашем аккаунте исчерпан лимит действий dbt Copilot, `text_to_sql` не будет работать до сброса лимита. Другие инструменты удалённого MCP продолжат работать. Если вам нужна помощь, обратитесь к менеджеру вашего аккаунта.
:::
