- **По умолчанию (не задано):** Если запрос возвращает `unique_id`, dbt сохраняет только строки, у которых `unique_id` входит в выборку. Если запрос не возвращает `unique_id`, проверка выполняется для всего проекта. Это полезно для агрегатных проверок, например «в проекте есть хотя бы одна модель».
- **`none`:** Проверка всегда выполняется для всего проекта, игнорируя любые селекторы. Используйте это значение, чтобы явно задать проверку всего проекта.
- **Имя столбца или список имён столбцов:** dbt сохраняет строку, если идентификатор хотя бы в одном из указанных столбцов входит в выборку. Каждый указанный столбец должен присутствовать в результате, иначе проверка завершится с ошибкой. Используйте этот вариант для проверок, которые возвращают связи между ресурсами (рёбра).
