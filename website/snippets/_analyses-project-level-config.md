Чтобы настроить анализы на уровне проекта, установите флаг [`require_corrected_analysis_fqns`](/reference/global-configs/behavior-flags/require_corrected_analysis_fqns) в значение `true` и добавьте блок `analyses` в файл `dbt_project.yml`. Конфигурация на уровне проекта применяется к существующим анализам в папке `analyses/` &mdash; например, настройка `+enabled: false` отключает их все.
