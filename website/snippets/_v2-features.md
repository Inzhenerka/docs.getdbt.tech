## Что вы получаете с v2 {#what-you-get-with-v2}

Для наиболее эффективной работы с dbt используйте dbt v2 с расширением dbt для VS Code, чтобы получить доступ к следующим возможностям:

- **Рабочие процессы dbt v1** (кроме dbt docs v1)
- [**Обнаружение синтаксических ошибок**](/docs/dbt-extension-features?version=2#live-error-detection)<sup>*</sup> (Jinja, YAML, SQL) 
- [**dbt lint**](/reference/commands/lint?version=2) <sup>*</sup> 
- [**dbt docs v2**](/reference/commands/cmd-docs?version=2#dbt-docs-v2)<sup>*</sup> (облегчённая или полная версия): полная версия включает отслеживание происхождения данных на уровне столбцов.
- [**<Term id="lsp" />**](/docs/about-dbt-lsp?version=2)<sup>*</sup> (облегчённая версия): переход к ref, source и макросам 
- [**Полная версия <Term id="lsp" />**](/docs/about-dbt-lsp?version=2): CTE, просмотр схемы при наведении и другие возможности 
- [**Понимание SQL, проверка типов и анализ влияния изменений**](/blog/the-levels-of-sql-comprehension)
- [**Точное отслеживание происхождения данных на уровне столбцов**](/docs/explore/column-level-lineage?version=2)

<sup>*</sup> Бесплатно навсегда. Правда!

Подключите свою учётную запись <Constant name="dbt_platform" /> к редактору, чтобы получить дополнительные расширенные возможности, например вкладку **Catalog**.

Подробнее о возможностях, доступных в VS Code, см. в разделе [Возможности расширения dbt для VS Code](/docs/dbt-extension-features).
