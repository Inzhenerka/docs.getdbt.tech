Проекты OpenAI с включёнными [настройками резидентности данных](https://platform.openai.com/docs/guides/your-data#data-residency-controls), настроенные для США (регион проекта — US), в настоящее время не поддерживают BYOK. В этих проектах можно использовать только ключ API, указанный в конфигурации платформы dbt. Указание пользовательских конечных точек, необходимых для обеспечения резидентности данных, пока не поддерживается, и мы рассматриваем возможное решение этой проблемы.

Чтобы использовать BYOK, убедитесь, что в вашем проекте OpenAI не включены настройки резидентности данных. Проекты без заданного региона используют стандартную конечную точку OpenAI (`https://api.openai.com`) и поддерживают BYOK.
