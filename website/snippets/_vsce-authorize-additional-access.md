:::note Предоставление дополнительных разрешений

При регистрации в расширении dbt для VS Code вам может быть предложено предоставить больше разрешений, чем при входе через CLI (или наоборот). Это ожидаемое поведение &mdash; некоторым функциям расширения требуются более широкие права доступа, чем те, которые вы предоставили при первоначальном входе. Вы можете предоставить запрашиваемые разрешения, используя ту же учетную запись <Constant name="dbt_platform" />, которой уже пользуетесь, поэтому для CLI и расширения dbt для VS Code достаточно одной учетной записи.

Подробнее о том, в каких случаях требуется повторная авторизация, см. в разделе [Истечение срока действия сеанса и повторная авторизация](/docs/sign-in-dbt-extension#session-expiry-and-re-authorization).

:::
