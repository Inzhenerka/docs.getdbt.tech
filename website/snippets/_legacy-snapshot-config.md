:::info
Начиная с [канала релизов <Constant name="dbt" /> **v1 Latest**](/docs/dbt-versions/dbt-release-tracks) и dbt v1.9, определение снимков в файле `.sql` с помощью блока конфигурации считается устаревшим методом. Вы можете определять снимки в YAML-файлах свойств, используя новейшие [настройки для снимков](/docs/build/snapshots#configuring-snapshots). Для новых снимков мы рекомендуем использовать эти настройки. Чтобы применить их к существующим снимкам, потребуется выполнить [миграцию](#snapshot-configuration-migration).
:::
