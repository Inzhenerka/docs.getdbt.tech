:::info Межпроектные ссылки не поддерживаются в последней версии спецификации YAML для Semantic Layer
При использовании [dbt Mesh](/best-practices/how-we-mesh/mesh-1-intro) с [Semantic Layer](/docs/use-dbt-semantic-layer/dbt-sl) [ссылки на модели из других проектов](/reference/dbt-jinja-functions/ref#ref-project-specific-models) поддерживаются только в устаревшей спецификации YAML, где семантические модели определяются как ресурсы верхнего уровня и могут ссылаться на модели из других проектов.

В [последней версии спецификации YAML](/docs/build/latest-metrics-spec) семантические модели определяются в YAML-файлах моделей, и межпроектные ссылки пока не поддерживаются. Поддержку этой возможности в последней версии спецификации планируется добавить в одном из будущих выпусков.
:::
