:::warning Поддержка dbt v1.3 – v1.7 будет прекращена <Constant name="legacy_deprecation_date" />
Версии dbt v1.3-v1.7 достигли [конца жизненного цикла](/docs/dbt-versions#end-of-life-versions), и их поддержка будет прекращена <Constant name="legacy_deprecation_date" />. После этой даты dbt Labs больше не будет поддерживать эти версии, и они будут удалены из <Constant name="dbt_platform" />.

До этой даты переведите свои окружения на [поддерживаемую версию dbt](/docs/dbt-versions) или [канал выпусков](/docs/dbt-versions/dbt-release-tracks), чтобы продолжать получать обновления и поддержку. Подробнее см. в руководстве [Переход с устаревших версий dbt](/guides/migrate-off-legacy-dbt-versions?step=1).
:::
