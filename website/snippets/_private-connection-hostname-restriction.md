При управлении частными подключениями учитывайте следующее:

- <Constant name="dbt" /> не поддерживает [переменные окружения](/docs/build/environment-variables) при настройке конечных точек приватного подключения. Используйте [расширенные атрибуты](/docs/dbt-platform-environments#extended-attributes), которые можно настроить для окружений разработки и развёртывания.

- [Административный API v3](/dbt-cloud/api-v3) позволяет управлять конечными точками приватных подключений программно. Через него можно [получить список](https://docs.getdbt.com/dbt-cloud/api-v3#/operations/List%20Private%20Endpoints), [создать](https://docs.getdbt.com/dbt-cloud/api-v3#/operations/Create%20Private%20Endpoints%20List%20Alias%20View), [получить сведения](https://docs.getdbt.com/dbt-cloud/api-v3#/operations/Retrieve%20Private%20Endpoint), [обновить](https://docs.getdbt.com/dbt-cloud/api-v3#/operations/Update%20Private%20Endpoints%20Detail%20View), [удалить](https://docs.getdbt.com/dbt-cloud/api-v3#/operations/Delete%20Private%20Endpoints%20Detail%20View).
