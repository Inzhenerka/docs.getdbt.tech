<Constant name="wizard" /> также позволяет генерировать SQL-код непосредственно в SQL-файле в [<Constant name="studio_ide" />](/docs/platform/studio-ide/develop-in-studio), используя запросы на естественном языке. Это означает, что вы можете переписывать или добавлять отдельные фрагменты SQL-файла без необходимости редактировать весь файл. 

Этот интеллектуальный инструмент на базе ИИ упрощает разработку SQL-кода, сокращая количество ошибок, легко справляясь с задачами любой сложности и экономя ценное время. [Окно запросов](#use-the-prompt-window) <Constant name="wizard" />, доступное по сочетанию клавиш, позволяет без труда генерировать повторяющийся или сложный SQL-код, чтобы вы могли сосредоточиться на задачах более высокого уровня. 

Используйте окно запросов dbt Wizard для таких задач, как:

- написание продвинутых трансформаций  
- эффективное выполнение массовых правок  
- создание сложных паттернов, например regex  

### Используйте окно промпта {#use-the-prompt-window}

Откройте окно ИИ-запросов <Constant name="wizard" /> с помощью сочетания клавиш Cmd+B (Mac) или Ctrl+B (Windows), чтобы:

#### 1. Создать SQL с нуля
- Используйте сочетание клавиш Cmd+B (Mac) или Ctrl+B (Windows), чтобы создать SQL с нуля.
- Введите инструкции на естественном языке, чтобы сгенерировать SQL-код под ваши задачи.
- Попросите <Constant name="wizard" /> исправить код или добавить определённый фрагмент SQL-файла.

<Lightbox src="/img/docs/dbt-platform/platform-ide/copilot-sql-generation-prompt.png" width="90%" title="Окно запросов dbt Wizard, доступное по сочетанию клавиш Cmd+B (Mac) или Ctrl+B (Windows)" />

#### 2. Отредактировать существующий SQL-код
- Выделите фрагмент SQL-кода и нажмите Cmd+B (Mac) или Ctrl+B (Windows), чтобы открыть окно запросов для редактирования.
- Используйте эту возможность, чтобы доработать или изменить отдельные фрагменты кода под ваши задачи.
- Попросите <Constant name="wizard" /> исправить код или добавить определённый фрагмент SQL-файла.

#### 3. Просмотреть различия, чтобы быстро оценить влияние изменений перед их применением
- После создания предложения <Constant name="wizard" /> показывает наглядное представление различий («diff»), которое помогает сравнить предлагаемые изменения с существующим кодом:
  - **Зелёный**: обозначает новый код, который будет добавлен, если вы примете предложение.
  - **Красный**: выделяет существующий код, который будет удалён или заменён в результате применения предлагаемых изменений.

#### 4. Принять или отклонить предложения {#4-accept-or-reject-suggestions}
- **Accept**: если сгенерированный SQL соответствует вашим требованиям, нажмите кнопку **Accept**, чтобы применить изменения напрямую к вашему `.sql`‑файлу в IDE.  
- **Reject**: если предложение не соответствует вашему запросу/промпту, нажмите **Reject**, чтобы отклонить сгенерированный SQL без внесения изменений и начать заново.  

#### 5. Сгенерировать код заново {#5-regenerate-code}
- Чтобы сгенерировать код заново, нажмите клавишу **Escape** на клавиатуре (или кнопку Reject во всплывающем окне). Это удалит сгенерированный код и вернёт курсор в поле ввода запроса.  
- Обновите запрос и нажмите **Enter**, чтобы попробовать другую генерацию. Нажмите **Escape** ещё раз, чтобы полностью закрыть всплывающее окно.  

После принятия предложения вы можете продолжать использовать окно запросов для генерации дополнительного SQL‑кода и коммитить изменения в ветку.
