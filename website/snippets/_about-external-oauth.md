:::note 

Эта функция в настоящее время доступна только для провайдеров удостоверений Okta и Entra ID.

:::

Тарифные планы Enterprise и Enterprise+ в <Constant name="dbt" /> поддерживают аутентификацию OAuth через внешних провайдеров. Когда включена функция **External OAuth**, пользователи могут авторизоваться с помощью своих учётных данных, используя единый вход (SSO) через поставщика удостоверений (IdP). External OAuth предоставляет пользователям доступ к нескольким приложениям, включая <Constant name="dbt" />, без передачи сервису их статических учётных данных. Это упрощает для пользователей процесс аутентификации в средах разработки и обеспечивает дополнительный уровень безопасности вашей учётной записи <Constant name="dbt" />.
