Чтобы заполнить автоматически определяемые типы столбцов моделей и данные о происхождении на уровне столбцов, используйте вместе с [`--static-analysis strict`](/docs/build/about-static-analysis). Без этого флага `dbt.node_columns` содержит только столбцы, объявленные в YAML, а `dbt.column_lineage` не содержит данных о происхождении.
