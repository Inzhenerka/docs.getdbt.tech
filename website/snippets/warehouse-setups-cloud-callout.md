:::info Файл `profiles.yml` нужен только для dbt v1 и dbt v2
Если вы используете <Constant name="dbt_platform" />, создавать файл `profiles.yml` не нужно. Этот файл необходим только при локальном использовании v1 или v2. Подробнее о предварительных требованиях для v2 см. в разделе [Поддерживаемые возможности](/docs/dbt/supported-features). Чтобы подключить вашу платформу данных к <Constant name="dbt" />, см. раздел [О платформах данных](/docs/platform/connect-data-platform/about-connections).
:::
