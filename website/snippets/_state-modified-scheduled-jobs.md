[`state:modified`](/reference/node-selection/methods#state) и `state:modified+` обнаруживают только изменения в коде проекта, конфигурации или метаданных, учитываемых в манифесте, &mdash; но не изменения в самих данных, например появление новых строк в исходной таблице. Если dbt не обнаруживает изменений в коде или конфигурации с момента последнего создания манифеста, используемого для отложенного выполнения, задание завершается успешно, не создавая ни одной модели. Это ожидаемое поведение.

Если ваше задание должно создавать модели при каждом запуске по расписанию независимо от изменений в коде, удалите из него селектор `state:modified`. Используйте его только для [CI](/docs/deploy/ci-jobs) или [заданий слияния](/docs/deploy/merge-jobs), цель которых — создавать только то, что изменилось в конкретном pull request или при слиянии.
