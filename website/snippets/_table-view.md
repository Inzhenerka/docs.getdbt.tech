Используйте кнопки **All** и **Jobs** для переключения между представлениями:
- **All**: Показывает агрегированные данные о затратах по всем заданиям проекта.
- **Jobs**: Показывает данные о затратах в разбивке по отдельным заданиям.

При просмотре таблицы можно экспортировать данные в файл CSV с помощью кнопки **Download**. Если выбран вариант **Jobs**, экспортируемый файл CSV содержит данные на уровне отдельных заданий.
