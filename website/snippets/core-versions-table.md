Все функциональные возможности v1, начиная с выпуска v1.7, доступны в [каналах обновлений <Constant name="dbt" />](/docs/dbt-versions/dbt-release-tracks), которые обеспечивают автоматическое обновление с периодичностью, подходящей вашей команде.

<sup>1</sup> Использование каналов обновлений обязательно для тарифных планов Developer и Starter в <Constant name="dbt" />. Учётные записи, использующие более старые версии dbt, будут переведены на канал обновлений **v1 Latest**.

Для клиентов <Constant name="dbt" />: dbt Labs настоятельно рекомендует переводить среды со старых и неподдерживаемых версий на [каналы обновлений](/docs/dbt-versions/dbt-release-tracks) или поддерживаемую версию. С <Constant name="legacy_deprecation_date" /> dbt Labs выведет из эксплуатации версии v1 с v1.3 по v1.7, после чего они станут недоступны в <Constant name="dbt_platform" />.
