- Рекомендуем использовать URL [https://login.dbt.com](https://login.dbt.com) для входа в <Constant name="dbt_platform"/>. После ввода адреса электронной почты dbt отправит на него код подтверждения. Подтвердив адрес электронной почты, вы сможете просмотреть доступные вам аккаунты в разных экземплярах платформы и выбрать аккаунт для открытия. Подробное описание процесса входа см. в разделе [Вход в платформу dbt](/docs/platform/about-platform/login).
- Вы также можете открыть свой аккаунт, используя его **Access URL** из раздела **Account settings**, если этот URL вам уже известен. Подробнее см. в разделе [Доступ, регионы и IP-адреса](/docs/platform/about-platform/access-regions-ip-addresses).
- Администраторы аккаунта могут включать и отключать обнаружение аккаунта с помощью параметра **Enable global account discovery** в разделе [Настройки аккаунта](/docs/platform/account-settings#enable-global-account-discovery). Если обнаружение аккаунта отключено, пользователи входят с помощью **Access URL** аккаунта и существующей конфигурации [SSO](/docs/platform/manage-access/sso-overview), если она настроена.
