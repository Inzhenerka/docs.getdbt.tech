:::note Линтинг в dbt v2
Задания CI, выполняемые на v2, автоматически используют встроенную команду [`dbt lint`](/reference/commands/lint?version=2.0) вместо SQLFluff. `dbt lint` совместима с SQLFluff: она читает существующий файл конфигурации `.sqlfluff`, использует те же коды правил и учитывает комментарии `-- noqa` для подавления предупреждений.
:::
