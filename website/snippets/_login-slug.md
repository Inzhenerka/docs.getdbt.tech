Чтобы заполнить этот раздел, вам понадобится слаг URL для входа. Этот слаг определяет URL-адрес, по которому пользователи вашей учетной записи могут входить в приложение. dbt автоматически генерирует слаги URL для входа, и изменить их нельзя. Слаг содержит только буквы, цифры и дефисы.
Например, слаг URL для входа для dbt Labs может выглядеть так: `dbt-labs-afk123`.
Слаги URL для входа уникальны среди всех учетных записей <Constant name="dbt" />.

Пользователи также могут войти через [https://login.dbt.com](https://login.dbt.com), чтобы увидеть учетные записи, к которым у них есть доступ в разных экземплярах. Корпоративный URL для входа, содержащий ваш слаг, по-прежнему используется для сценариев единого входа (SSO), инициируемых вашим поставщиком удостоверений (IdP).
