Отслеживайте задания <Constant name="dbt" />, чтобы находить возможности для улучшения, и настраивайте оповещения для своевременного уведомления нужных людей или команд. 

В этом разделе документации рассматриваются различные возможности <Constant name="dbt" />, которые помогают отслеживать задания и настраивать оповещения для обеспечения бесперебойной оркестрации, в том числе:

- [Визуализация и оркестрация зависимых экспозиций](/docs/deploy/orchestrate-exposures) <Lifecycle status="managed,managed_plus" /> &mdash; Автоматически визуализируйте и оркестрируйте экспозиции на основе дашбордов и заблаговременно обновляйте лежащие в их основе источники данных во время выполнения заданий dbt по расписанию.
- [Использование артефактов](/docs/deploy/artifacts) &mdash; <Constant name="dbt" /> генерирует и сохраняет артефакты вашего проекта, которые используются для таких возможностей, как создание документации проекта и формирование отчётов об актуальности источников.  
- [Уведомления о заданиях](/docs/deploy/job-notifications) &mdash; Получайте уведомления по электронной почте, в Slack или Microsoft Teams, когда запуск задания завершается успешно, выдаёт предупреждения, завершается ошибкой или отменяется.  
- [Уведомления о моделях](/docs/deploy/model-notifications) &mdash; Получайте уведомления по электронной почте о любых проблемах с моделями и тестами сразу после их возникновения во время выполнения задания.  
- [Повторный запуск заданий](/docs/deploy/retry-jobs) &mdash; Повторно запускайте задания, завершившиеся ошибкой, с самого начала или с места сбоя.  
- [Просмотр запусков](/docs/deploy/run-visibility) &mdash; Просматривайте историю запусков, чтобы находить возможности для улучшения заданий, выполняемых по расписанию.  
- [Актуальность источников](/docs/deploy/source-freshness) &mdash; Контролируйте управление данными, включив создание снимков для фиксации актуальности ваших источников данных.  
- [Вебхуки](/docs/deploy/webhooks) &mdash; Используйте вебхуки для отправки событий о статусах ваших заданий dbt в другие системы.

Чтобы настроить и добавить data health tiles для просмотра freshness данных и проверок качества данных на вашем дашборде, обратитесь к разделу [data health tiles](/docs/explore/data-tile).
