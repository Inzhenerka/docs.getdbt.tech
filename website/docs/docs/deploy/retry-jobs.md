Если запуск задания dbt завершился со статусом **Error**, вы можете повторно запустить его с начала или с места сбоя в <Constant name="dbt" />.

## Предварительные условия {#prerequisites}

- У вас есть [учётная запись <Constant name="dbt" />](https://www.getdbt.com/signup).
- Вы используете [dbt версии](/docs/dbt-versions/upgrade-dbt-platform-version) 1.6 или новее.
- dbt может успешно разобрать проект и сгенерировать [манифест](/reference/artifacts/manifest-json)
- Последний запуск задания не завершился успешно. Текущий статус этого запуска — **Error**.
    - Команда задания, завершившаяся ошибкой во время запуска, должна поддерживать [команду retry](/reference/commands/retry).

## Повторный запуск задачи с ошибкой {#rerun-an-errored-job}

1. Выберите **Deploy** на верхней панели навигации, затем выберите **Run History.** 
2. Выберите запуск задания, завершившийся с ошибкой. 
3. На вкладке **Run Summary** страницы **Run** задания разверните шаг запуска, завершившийся с ошибкой. Значок :x: обозначает шаг с ошибкой. 
4. Изучите сообщение об ошибке и определите, как её исправить. Внеся изменения, сохраните их и создайте коммит в своём [репозитории <Constant name="git" />](/docs/platform/git/git-version-control).
5. Вернитесь на страницу **Run** задания. В правом верхнем углу нажмите **Rerun** и выберите **Rerun from start** или **Rerun from failure**.
    
    Если вы выбрали повторный запуск с места сбоя, откроется модальное окно **Rerun failed steps**. В нём перечислены шаги запуска, которые будут выполнены: шаг, завершившийся с ошибкой, и все пропущенные шаги. Чтобы подтвердить выполнение этих шагов, нажмите **Rerun from failure**. Задание запустится повторно с команды, завершившейся с ошибкой в предыдущем неудачном запуске. Об этом сообщает баннер в верхней части вкладки **Run Summary** с текстом «This run resumed execution from last failed step» (Выполнение этого запуска возобновлено с последнего шага, завершившегося с ошибкой).
