# Использование данных и телеметрия <Constant name="wizard" /> CLI

<IntroText>
<Constant name="wizard" /> CLI собирает анонимную телеметрию об использовании продукта, чтобы улучшать взаимодействие с ИИ-агентом, изучать сценарии использования, оптимизировать производительность и учитывать вычислительные затраты, не собирая ваш код, запросы, промпты, ответы или содержимое файлов.
</IntroText>

## Отключение телеметрии клиента

<Constant name="wizard" /> CLI учитывает следующие способы отключения телеметрии, проверяя их в указанном порядке:

1. Установите `DO_NOT_TRACK=1`.
2. Установите `DBT_SEND_ANONYMOUS_USAGE_STATS=false`.
3. Сохраните настройку согласия на сбор телеметрии в `~/.dbt/.user.yml`.

Использование любого из этих способов отключает телеметрию клиента <Constant name="wizard" /> CLI.

## Какие данные dbt Wizard не собирает

<Constant name="wizard" /> CLI не собирает:

- Содержимое промптов или ответов.
- SQL-запросы, пути к файлам или имена узлов dbt.
- Аргументы вызовов инструментов MCP или результаты их выполнения.
- API-ключи или токены в исходном виде. Идентификаторы хешируются перед передачей.
- Сообщения об ошибках, содержащие пользовательские данные. Для ошибок собирается только класс или код.

## Собираемые события

<SimpleTable>

| Событие | Когда собирается | Зачем собирается |
| --- | --- | --- |
| Запрос к LLM завершён или завершился с ошибкой | При завершении запроса к LLM | Учёт использования токенов и модели, мониторинг задержек, частоты ошибок и распределение затрат |
| Сеанс Wizard начат или завершён | Когда пользователь открывает или закрывает сеанс <Constant name="wizard" /> CLI | Учёт активных пользователей за неделю, длительности сеансов, востребованности моделей и использования клиентских интерфейсов |
| Шаг диалога Wizard завершён | После обработки сообщения пользователя и формирования ответа ИИ | Оценка глубины взаимодействия, расхода токенов, использования моделей, статуса и длительности |
| Использование инструмента Wizard | При каждом вызове инструмента агентом | Оценка востребованности инструментов, надёжности и производительности |
| Отзыв о диалоге | Если вы отправляете отзыв о диалоге с <Constant name="wizard" />. | Мы можем хранить связанную с отзывом историю диалога до 400 дней для его изучения. Эти истории диалогов не используются для обучения моделей и могут быть удалены по письменному запросу. |

</SimpleTable>

Телеметрия инструментов фиксирует тип инструмента, его имя, наличие ошибки при вызове и время выполнения. Аргументы инструментов и результаты их выполнения не собираются.

## Обработка данных

- Телеметрия передаётся по HTTPS в инфраструктуру приёма данных dbt Labs.
- События хранятся во внутреннем хранилище данных dbt Labs.
- Телеметрия не передаётся третьим сторонам.
- API-ключи и токены не передаются в исходном виде.
- При локальной разработке у пользователей, отключивших телеметрию с помощью поддерживаемых переменных окружения, клиент <Constant name="wizard" /> CLI не генерирует события телеметрии.
