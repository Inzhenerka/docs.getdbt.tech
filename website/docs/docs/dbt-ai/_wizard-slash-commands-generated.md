## Слеш-команды

Введите `/` в поле ввода сообщения, чтобы открыть меню выбора команд. Используйте клавиши со стрелками для навигации или продолжайте вводить текст для фильтрации. Нажмите **Tab**, чтобы поставить команду в очередь во время выполнения задачи — она выполнится в конце текущего хода.
