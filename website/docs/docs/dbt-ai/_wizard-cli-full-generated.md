## Как пользоваться этим справочником

- **Флаг** — полная запись флага при вводе. Короткие флаги (например, `-m`) приведены в столбце «Короткая форма».
- **Тип** — `boolean` (наличие/отсутствие), `string`, `path` или перечисление допустимых значений.
- **Описание** — действие флага и ситуации, в которых его следует использовать.
- Глобальные флаги применяются к базовой интерактивной команде `wizard`. У подкоманд могут быть другие наборы флагов; при автоматизации используйте раздел соответствующей команды.

## Глобальные флаги {#global-flags}

Эти флаги работают с базовой интерактивной командой `wizard`.

| Флаг | Короткая форма | Тип | Описание |
|------|-------|------|-------------|
| `-c, --config <key=value>` | `-c` | string | Переопределяет значение конфигурации, которое в противном случае загружается из `~/.dbt/wizard/config.toml`. Для переопределения вложенных значений используйте путь с точками (`foo.bar.baz`). Часть `value` разбирается как TOML. Если разобрать её как TOML не удаётся, исходная строка используется как литерал. |
| `--enable <FEATURE>` | — | string | Включает функцию (можно указать несколько раз). Эквивалентно `-c features.&lt;name&gt;=true` |
| `--disable <FEATURE>` | — | string | Отключает функцию (можно указать несколько раз). Эквивалентно `-c features.&lt;name&gt;=false` |
| `--remote <ADDR>` | — | string | Подключает TUI к конечной точке удалённого сервера приложений. |
| `--remote-auth-token-env <ENV_VAR>` | — | string | Имя переменной окружения, содержащей bearer-токен для отправки по WebSocket удалённому серверу приложений |
| `--strict-config` | — | boolean | Завершает работу с ошибкой, если config.toml содержит поля, не распознаваемые этой версией wizard |
| `-i, --image <FILE>...` | `-i` | path | Необязательные изображения для прикрепления к начальному запросу |
| `-m, --model <MODEL>` | `-m` | enum | Модель, которую должен использовать агент |
| `--oss` | — | boolean | Использует провайдера с открытым исходным кодом |
| `--local-provider <OSS_PROVIDER>` | — | enum | Указывает, какого локального провайдера использовать (lmstudio или ollama). Если при использовании --oss провайдер не указан, используется значение по умолчанию из конфигурации или предлагается выбор |
| `-p, --profile <CONFIG_PROFILE>` | `-p` | path | Профиль конфигурации из config.toml, задающий параметры по умолчанию |
| `--profile-v2 <CONFIG_PROFILE_V2>` | — | path | Применяет $DBT_WIZARD_HOME/&lt;name&gt;.config.toml поверх базовой пользовательской конфигурации |
| `-s, --sandbox <SANDBOX_MODE>` | `-s` | enum | Выбирает политику песочницы для выполнения команд оболочки, сгенерированных моделью |
| `--dangerously-bypass-approvals-and-sandbox` | — | boolean | Пропускает все запросы подтверждения и выполняет команды без песочницы. КРАЙНЕ ОПАСНО. Предназначено исключительно для запуска в средах с внешней изоляцией |
| `--dangerously-bypass-hook-trust` | — | boolean | Запускает включённые хуки, не требуя сохранённого подтверждения доверия к ним для этого вызова. ОПАСНО. Предназначено только для автоматизации, в которой источники хуков уже проверяются |
| `-C, --cd <DIR>` | `-C` | path | Указывает агенту использовать заданный каталог в качестве корневого рабочего каталога |
| `--add-dir <DIR>` | — | path | Дополнительные каталоги, доступные для записи наряду с основным рабочим пространством |
| `-a, --ask-for-approval <APPROVAL_POLICY>` | `-a` | enum | Настраивает, когда модели требуется одобрение человека перед выполнением команды |
| `--search` | — | boolean | Включает веб-поиск в реальном времени. При включении модели доступен встроенный инструмент Responses `web_search` (без одобрения каждого вызова) |
| `--no-alt-screen` | — | boolean | Отключает режим альтернативного экрана |

## exec {#exec}

Запускает wizard в неинтерактивном режиме

```bash
wizard exec [OPTIONS] <COMMAND> [ARGS]
```

**Аргументы:**

| Аргумент | Описание |
|----------|-------------|
| `[PROMPT]` | Начальные инструкции для агента. Если аргумент не указан (или используется `-`), инструкции считываются из stdin. Если stdin передаётся через конвейер и при этом указан запрос, содержимое stdin добавляется в виде блока `&lt;stdin&gt;` |

| Флаг | Короткая форма | Тип | Описание |
|------|-------|------|-------------|
| `-c, --config <key=value>` | `-c` | string | Переопределяет значение конфигурации, которое в противном случае загружается из `~/.dbt/wizard/config.toml`. Для переопределения вложенных значений используйте путь с точками (`foo.bar.baz`). Часть `value` разбирается как TOML. Если разобрать её как TOML не удаётся, исходная строка используется как литерал. |
| `--enable <FEATURE>` | — | string | Включает функцию (можно указать несколько раз). Эквивалентно `-c features.&lt;name&gt;=true` |
| `--disable <FEATURE>` | — | string | Отключает функцию (можно указать несколько раз). Эквивалентно `-c features.&lt;name&gt;=false` |
| `--strict-config` | — | boolean | Завершает работу с ошибкой, если config.toml содержит поля, не распознаваемые этой версией wizard |
| `-i, --image <FILE>...` | `-i` | path | Необязательные изображения для прикрепления к начальному запросу |
| `-m, --model <MODEL>` | `-m` | enum | Модель, которую должен использовать агент |
| `--oss` | — | boolean | Использует провайдера с открытым исходным кодом |
| `--local-provider <OSS_PROVIDER>` | — | enum | Указывает, какого локального провайдера использовать (lmstudio или ollama). Если при использовании --oss провайдер не указан, используется значение по умолчанию из конфигурации или предлагается выбор |
| `-p, --profile <CONFIG_PROFILE>` | `-p` | path | Профиль конфигурации из config.toml, задающий параметры по умолчанию |
| `--profile-v2 <CONFIG_PROFILE_V2>` | — | path | Применяет $DBT_WIZARD_HOME/&lt;name&gt;.config.toml поверх базовой пользовательской конфигурации |
| `-s, --sandbox <SANDBOX_MODE>` | `-s` | enum | Выбирает политику песочницы для выполнения команд оболочки, сгенерированных моделью |
| `--dangerously-bypass-approvals-and-sandbox` | — | boolean | Пропускает все запросы подтверждения и выполняет команды без песочницы. КРАЙНЕ ОПАСНО. Предназначено исключительно для запуска в средах с внешней изоляцией |
| `--dangerously-bypass-hook-trust` | — | boolean | Запускает включённые хуки, не требуя сохранённого подтверждения доверия к ним для этого вызова. ОПАСНО. Предназначено только для автоматизации, в которой источники хуков уже проверяются |
| `-C, --cd <DIR>` | `-C` | path | Указывает агенту использовать заданный каталог в качестве корневого рабочего каталога |
| `--add-dir <DIR>` | — | path | Дополнительные каталоги, доступные для записи наряду с основным рабочим пространством |
| `--skip-git-repo-check` | — | boolean | Разрешает запуск wizard вне репозитория Git |
| `--ephemeral` | — | boolean | Запускает без сохранения файлов сеанса на диск |
| `--ignore-user-config` | — | boolean | Не загружает `$DBT_WIZARD_HOME/config.toml`; для аутентификации по-прежнему используется `DBT_WIZARD_HOME` |
| `--ignore-rules` | — | boolean | Не загружает пользовательские или проектные файлы execpolicy `.rules` |
| `--output-schema <FILE>` | — | path | Путь к файлу JSON Schema, описывающему структуру итогового ответа модели |
| `--color <COLOR>` | — | enum | Задаёт настройки цвета для вывода |
| `--json` | — | boolean | Выводит события в stdout в формате JSONL |
| `--include-subagent-events` | — | boolean | Если задан `--json`, собирает и выводит события субагентов с идентификаторами их потоков. Для каждого события субагента в строку JSONL добавляется поле `sub_agent_thread_id`, чтобы потребители могли отличать его от событий основного агента |
| `--no-validation` | — | boolean | Если задан, механизм допуска к проверке всегда отвечает "declined", поэтому субагент проверки никогда не запускается. Полезно для тестирования производительности, когда накладные расходы субагента нежелательны |
| `-o, --output-last-message <FILE>` | `-o` | path | Задаёт файл, в который следует записать последнее сообщение агента |
