[Пакеты dbt](/docs/build/packages) — это библиотеки с моделями, макросами и другими ресурсами для решения задач в определённой предметной области, которые используются в проектах dbt. Вы можете запрашивать пакеты проекта через Discovery API.

В [примере запроса](#example-query) показаны некоторые поля, которые можно запрашивать у объекта `packages`.

### Аргументы

При запросе `packages` можно использовать следующие аргументы:

<NodeArgsTable parent="AppliedState" name="packages" />

### Пример запроса {#example-query}

Вы можете указать `environmentId` и "model" в качестве типа ресурса, чтобы просмотреть все пакеты dbt в этой среде, содержащие ресурсы моделей:

```graphql
query {
  environment(id: 834) {
    applied {
      packages(resource: "model")
    }
  }
}
```
