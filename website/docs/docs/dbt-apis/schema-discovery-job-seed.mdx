Объект seed позволяет запрашивать информацию об определённом seed в рамках заданного задания.

### Аргументы

При запросе `seed` доступны следующие аргументы.

<NodeArgsTable parent="JobNode" name="seed" />

Ниже приведены наглядные примеры запросов и описана схема объекта seed.

### Пример запроса

Приведённый ниже пример запроса извлекает соответствующую информацию о заданном seed. Например, вы можете просмотреть время загрузки.

```graphql
{
  job(id: 123) {
    seed(uniqueId: "seed.jaffle_shop.raw_customers") {
      database
      schema
      uniqueId
      name
      status
      error
    }
  }
}
```
