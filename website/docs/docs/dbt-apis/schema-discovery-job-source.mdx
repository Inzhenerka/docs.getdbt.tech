Объект source позволяет запрашивать информацию об определённом источнике в заданном задании.

### Аргументы

При запросе `source` доступны следующие аргументы.

<NodeArgsTable parent="JobNode" name="source" />

Ниже приведены наглядные примеры запросов и описание схемы объекта source.

### Пример запроса

Приведённый ниже запрос получает актуальную информацию об определённом источнике. Например, вы можете просмотреть время загрузки и состояние (pass, fail, error) этого источника.

```graphql
{
  job(id: 123) {
    source(uniqueId: "source.jaffle_shop.snowplow.event") {
      uniqueId
      sourceName
      name
      state
      maxLoadedAt
      criteria {
        warnAfter {
          period
          count
        }
        errorAfter {
          period
          count
        }
      }
      maxLoadedAtTimeAgoInS
    }
  }
}
```
