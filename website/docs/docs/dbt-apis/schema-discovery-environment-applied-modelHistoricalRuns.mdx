Объект истории запусков модели позволяет запрашивать информацию об истории запусков модели. 

В разделе [Пример запроса](#example-query) показаны некоторые поля, которые можно запрашивать с помощью объекта `modelHistoricalRuns`. Полная схема со всеми доступными для запроса полями приведена в разделе [Поля](#fields).

### Аргументы

При запросе `modelHistoricalRuns` можно использовать следующие аргументы:

<NodeArgsTable parent="AppliedState" name="modelHistoricalRuns" />

### Пример запроса {#example-query}

Можно указать `environmentId` и `uniqueId` модели, чтобы получить модель `customers` из пакета `marketing` и историю её выполнения, включая показатели производительности и результаты тестов за последние 20 запусков, независимо от того, какое задание её запускало.

```graphql
query {
  environment(id: 834) {
    applied {
      modelHistoricalRuns(
        uniqueId: "model.marketing.customers" # Используйте следующий формат уникального идентификатора: RESOURCE_TYPE.PACKAGE_NAME.RESOURCE_NAME
        lastRunCount: 20
      ) {
        runId # Получить исторические результаты для конкретной модели
        runGeneratedAt
        executionTime # Посмотреть время сборки в разных запусках
        status
        tests {
          name
          status
          executeCompletedAt
        } # Посмотреть результаты тестов в разных запусках
      }
    }
  }
}
```
