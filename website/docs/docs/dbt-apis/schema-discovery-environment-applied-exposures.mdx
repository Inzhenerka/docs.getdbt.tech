[Потребители данных (exposures)](/docs/build/exposures) — это ресурсы dbt, которые представляют последующее использование вашего проекта, например в дашбордах, приложениях или конвейерах обработки данных для задач Data Science. Вы можете запрашивать exposures через Discovery API, чтобы понять, какие объекты зависят от ваших моделей.

В разделе [Пример запроса](#example-query) показаны некоторые поля, которые можно запрашивать у объекта `exposures`. В разделе [Поля](#fields) приведена полная схема со всеми полями, доступными для запроса.

### Пример запроса {#example-query}

Вы можете указать `environmentId`, `first: 100` и фильтр по `uniqueIds` моделей, чтобы получить всех последующих потребителей данных (дашборды, приложения и т. д.), которые зависят от модели `customers` в пакете `marketing`, ограничив выборку первыми 100 результатами:

```graphql
query {
  environment(id: 834) {
    applied {
      exposures(
        filter: {
          uniqueIds: ["model.marketing.customers"] # Use this format for unique ID: RESOURCE_TYPE.PACKAGE_NAME.RESOURCE_NAME
        }, 
        first: 100
      ) {
        edges {
          node {
            accountId
            exposureType
            fqn
            projectId
            url
          }
        }
      }
    }
  }
}
```
