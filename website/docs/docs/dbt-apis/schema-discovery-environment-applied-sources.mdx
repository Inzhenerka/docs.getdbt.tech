[Источники](/docs/build/sources) позволяют задавать имена и описания для данных, загружаемых в ваше хранилище инструментами извлечения и загрузки данных. Вы можете запрашивать источники через Discovery API.

В разделе [Пример запроса](#example-query) показаны некоторые поля, которые можно запрашивать с помощью объекта `sources`. В разделе [Поля](#fields) приведена полная схема со всеми полями, доступными для запросов.

### Аргументы

При запросе `sources` можно использовать следующие аргументы:

<NodeArgsTable parent="AppliedState" name="sources" />

### Пример запроса {#example-query}

Вы можете указать `environmentId` и отфильтровать источники по имени базы данных, чтобы получить сведения об актуальности и статусе выполнения для первых 100 источников из указанной базы данных:

```graphql
query {
  environment(id: 834) {
    applied {
      sources(
        filter: {
          database: "analytics"
        }, 
        first: 100
      ) {
        edges {
          node {
            name
            fqn
            description
            filePath
            freshness {
              freshnessChecked
              freshnessStatus
            }
            sourceName
            sourceDescription
            tests {
              name
              description
              testType
              executionInfo {
                lastRunStatus
              }
            }
          }
        }
      }
    }
  }
}
```
