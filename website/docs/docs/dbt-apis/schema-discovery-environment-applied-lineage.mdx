Объект <Term id="data-lineage">lineage</Term> позволяет запрашивать информацию о происхождении данных и зависимостях между вашими ресурсами. 

В разделе [Пример запроса](#example-query) показаны некоторые поля, которые можно запрашивать с помощью объекта `lineage`. Полная схема со всеми доступными для запроса полями приведена в разделе [Поля](#fields).

### Аргументы

При запросе `lineage` можно использовать следующие аргументы:

<NodeArgsTable parent="AppliedState" name="lineage" />

### Пример запроса {#example-query}

Вы можете указать `environmentId` и отфильтровать ресурсы по типу "Model", чтобы получить информацию о происхождении данных для всех моделей в этой среде, включая их зависимости, тип материализации и метаданные:

```graphql
query {
  environment(id: 834) {
    applied {
      lineage(
        filter: {"types": ["Model"]} # Return results for the Model type
      ) {
        name
        resourceType
        filePath
        projectId
        materializationType
        parentIds
        tags
        uniqueId
      }
    }
  }
}
```
