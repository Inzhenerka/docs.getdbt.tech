Объект test позволяет запрашивать информацию о конкретном тесте.

### Аргументы

При запросе объекта `test` доступны следующие аргументы.

<NodeArgsTable parent="JobNode" name="test" />

Ниже приведены наглядные примеры запросов и схема объекта test (все поля, которые можно запросить).

### Пример запроса

Приведённый ниже пример запроса возвращает информацию о тесте, включая статус его результата. В порядке убывания серьёзности результат может принимать одно из следующих значений: "error", "fail", "warn" или "pass".

```graphql
{
  job(id: 123) {
    test(uniqueId: "test.internal_analytics.not_null_metrics_id") {
      runId
      accountId
      projectId
      uniqueId
      name
      columnName
      state
    }
  }
}
```

При запросе объекта `test` доступны следующие поля:

<SchemaTable nodeName="TestNode" />
