[Плитки состояния экспозиций](/docs/explore/data-tile) представляют сводную информацию о состоянии данных для их потребителей и могут встраиваться в инструменты, использующие эти данные. Вы можете запрашивать информацию об этих плитках через Discovery API.

В [примере запроса](#example-query) показаны некоторые поля, которые можно запрашивать с помощью объекта `exposureTile`. Полная схема со всеми доступными для запроса полями приведена в разделе [Поля](#fields).

### Пример запроса {#example-query}

Вы можете указать `environmentId` и отфильтровать результаты по `uniqueId` модели, чтобы получить сведения о качестве данных и метаданных для плитки экспозиции, связанной с моделью `customers` в пакете `marketing`:

```graphql
query {
  environment(id: 834) {
    applied {
      exposureTile(
        filter: {uniqueId: "model.marketing.customers"} # Use this format for unique ID: RESOURCE_TYPE.PACKAGE_NAME.RESOURCE_NAME
      ) {
        accountId # The account ID of this node
        environmentId
        projectId
        exposureType
        filePath
        quality
      }
    }
  }
}
```
