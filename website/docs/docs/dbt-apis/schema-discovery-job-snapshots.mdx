Объект snapshots позволяет запрашивать информацию обо всех снимках в заданном задании.

### Аргументы

При запросе `snapshots` доступны следующие аргументы.

<NodeArgsTable parent="JobNode" name="snapshots" />

Ниже приведены наглядные примеры запросов и описание схемы объекта snapshots.

### Пример запроса

Аргументы database, schema и identifier необязательны. Это означает, что с помощью этой конечной точки можно:

- Найти конкретный снимок, указав `<database>.<schema>.<identifier>`
- Найти все снимки в базе данных и/или схеме, указав `<database>` и/или `<schema>`

#### Получение информации о снимках для задания

Пример запроса возвращает информацию обо всех снимках в этом задании.

```graphql
{
  job(id: 123) {
    snapshots(first: 10, after: "{somePaginationCursorValue}") {
      uniqueId
      name
      executionTime
      environmentId
      executeStartedAt
      executeCompletedAt
      paginationCursor
    }
  }
}
```
