[Снимки](/docs/build/snapshots) представляют собой копии ваших данных на определённый момент времени и позволяют отслеживать историю изменений. Вы можете запрашивать свои снимки через Discovery API.

В разделе [Пример запроса](#example-query) показаны некоторые поля, которые можно запрашивать с помощью объекта `snapshots`. Полная схема со всеми доступными для запроса полями приведена в разделе [Поля](#fields).

### Аргументы

### Пример запроса {#example-query}

Вы можете указать `environmentId`, задать фильтр по базе данных и ограничить результат первыми 100 записями, чтобы получить первые 100 снимков в базе данных `analytics`, включая информацию о производительности и статусе их выполнения:

```graphql
query {
  environment(id: 834) {
    applied {
      snapshots(
        filter: {
          database: "analytics"
        }, 
        first: 100
      ) {
        edges {
          node {
            executionInfo {
              compileCompletedAt
              compileStartedAt
              executeCompletedAt
              executeStartedAt
              executionTime
              lastRunStatus
              lastRunId
            }
            fqn
            name
          }
        }
      }
    }
  }
}
```
