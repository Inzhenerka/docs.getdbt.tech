Объект модели позволяет запрашивать информацию о конкретной модели в заданном задании.

### Аргументы

При запросе объекта `model` доступны следующие аргументы.

<NodeArgsTable parent="JobNode" name="model" />

Ниже приведены наглядные примеры запросов и схема объекта модели (все поля, которые можно запросить).

### Пример запроса для поиска родительских моделей и источников

В приведенном ниже примере запроса используются поля `parentsModels` и `parentsSources` для получения информации о родительских моделях и родительских источниках модели. Поля jobID и uniqueID содержат значения-заполнители, которые необходимо заменить собственными значениями.

```graphql
{
  job(id: 123) {
    model(uniqueId: "model.jaffle_shop.dim_user") {
      parentsModels {
        runId
        uniqueId
        executionTime
      }
      parentsSources {
        runId
        uniqueId
        state
      }
    }
  }
}

```

### Пример запроса времени выполнения модели

Приведенный ниже пример запроса может быть полезен для получения информации о времени выполнения конкретной модели (начало, окончание, продолжительность).

```graphql
{
  job(id: 123) {
    model(uniqueId: "model.jaffle_shop.dim_user") {
      runId
      projectId
      name
      uniqueId
      resourceType
      executeStartedAt
      executeCompletedAt
      executionTime
    }
  }
}
```

### Пример запроса информации на уровне столбцов

Следующий пример запроса позволяет получить дополнительные сведения о столбцах конкретной модели. Этот запрос будет работать, только если в рамках задания была сгенерирована документация, то есть была выполнена команда `dbt docs generate`.

```graphql
{
  job(id: 123) {
    model(uniqueId: "model.jaffle_shop.dim_user") {
      columns {
        name
        index
        type
        comment
        description
        tags
        meta
      }
    }
  }
}
```
