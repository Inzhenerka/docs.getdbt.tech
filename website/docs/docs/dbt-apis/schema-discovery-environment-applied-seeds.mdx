[Seeds](/docs/build/seeds) — это CSV-файлы в вашем проекте dbt, которые dbt может загрузить в ваше хранилище данных. Вы можете запрашивать seeds через Discovery API.

В разделе [Пример запроса](#example-query) показаны некоторые поля, которые можно запрашивать с помощью объекта `seeds`. Полная схема со всеми доступными для запроса полями приведена в разделе [Поля](#fields).

### Аргументы

### Пример запроса {#example-query}

Вы можете указать `environmentId`, отфильтровать результаты по базе данных и ограничить выборку первыми 100 записями, чтобы получить информацию о первых 100 seed-файлах в базе данных `analytics`, включая их метаданные и расположение файлов:

```graphql
query ($environmentId: BigInt!, $first: Int!, $filter: GenericMaterializedFilter) {
  environment(id: $environmentId) {
    applied {
      seeds(
        first: 100,
        filter: {
          database: "analytics"
        }
      ) {
        edges {
          node {
            description
            name
            filePath
            projectId
            fqn
            tags
            uniqueId
            resourceType
          }
        }
      }
    }
  }
}
```
