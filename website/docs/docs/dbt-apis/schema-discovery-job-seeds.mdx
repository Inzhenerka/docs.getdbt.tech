Объект seeds позволяет запрашивать информацию обо всех seeds в заданном задании.

### Аргументы

При запросе `seeds` доступны следующие аргументы.

<NodeArgsTable parent="JobNode" name="seeds" />

Ниже приведены примеры запросов и описание схемы объекта seeds.

### Пример запроса

Приведённый ниже пример запроса извлекает соответствующую информацию обо всех seeds в заданном задании. Например, вы можете просмотреть время загрузки.

```graphql
{
  job(id: 123) {
    seeds(first: 10, after: "{somePaginationCursorValue}") {
      uniqueId
      name
      executionTime
      status
      paginationCursor
    }
  }
}
```
