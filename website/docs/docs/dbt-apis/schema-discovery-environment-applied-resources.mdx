Объект resources позволяет постранично получать все ресурсы вашей среды.

В разделе [Пример запроса](#example-query) показаны некоторые поля, которые можно запрашивать с помощью объекта `resources`. Полная схема со всеми доступными для запроса полями приведена в разделе [Поля](#fields).

### Аргументы

При запросе `resources` можно использовать следующие аргументы:

<NodeArgsTable parent="AppliedState" name="resources" />

### Пример запроса {#example-query}

Вы можете указать `environmentId`, отфильтровать ресурсы по типу "Model" и ограничить выборку первыми 100 результатами, чтобы получить подробную информацию о первых 100 ресурсах моделей в этой среде, включая их метаданные, теги и расположение файлов:

```graphql
query {
  environment(id: 834) {
    applied {
      resources(
        filter: {
          types: [
            Model
          ]
        }, 
        first: 100
      ) {
        edges {
          node {
            accountId
            description
            environmentId
            filePath
            meta
            name
            projectId
            resourceType
            uniqueId
            tags
          }
        }
      }
    }
  }
}
```
