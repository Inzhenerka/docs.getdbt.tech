[Владельцы](/docs/build/groups) помогают определить пользователя или подразделение, ответственное за ресурс dbt. Для большинства ресурсов владельцы задаются в коде проекта с помощью групп. Экспозиции — исключение: для экспозиций, представляющих нижестоящие BI-ресурсы, сведения о владельцах автоматически извлекаются из соответствующего инструмента на основе того, кому принадлежит ресурс. Вы можете запрашивать сведения о владельцах через Discovery API.

В разделе [Пример запроса](#example-query) показаны некоторые поля, которые можно запрашивать с помощью объекта `owners`. Полную схему со всеми доступными для запроса полями см. в разделе [Поля](#fields).

### Пример запроса {#example-query}

Вы можете указать `environmentId` и значение "exposure" для `OwnerResourceType`, чтобы получить список людей, владеющих экспозициями (нижестоящими BI-ресурсами) в этой среде, включая их контактные данные.

```graphql
query {
  environment(id: 834) {
    applied {
      owners(resource: exposure) {
        email
        name
      }
    }
  }
}
```
