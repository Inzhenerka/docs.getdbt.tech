Объект exposure позволяет запрашивать информацию о конкретном exposure. Подробнее см. в разделе [Добавление exposures в DAG](/docs/build/exposures).

### Аргументы

При запросе `exposure` доступны следующие аргументы.

<NodeArgsTable parent="JobNode" name="exposure" />

Ниже приведены наглядные примеры запросов и описание схемы объекта exposure.

### Пример запроса

В приведенном ниже примере запрашивается информация об exposure, включая имя и адрес электронной почты владельца, URL, а также информацию о родительских источниках и моделях.

```graphql
{
  job(id: 123) {
    exposure(name: "my_awesome_exposure") {
      runId
      projectId
      name
      uniqueId
      resourceType
      ownerName
      url
      ownerEmail
      parentsSources {
        uniqueId
        sourceName
        name
        state
        maxLoadedAt
        criteria {
          warnAfter {
            period
            count
          }
          errorAfter {
            period
            count
          }
        }
        maxLoadedAtTimeAgoInS
      }
      parentsModels {
        uniqueId
      }
    }
  }
}
```
