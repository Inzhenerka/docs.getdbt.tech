[Теги](/reference/resource-configs/tags) позволяют классифицировать и группировать ресурсы в проекте dbt, обеспечивая возможность выборочного выполнения этих ресурсов и управления ими. Вы можете запрашивать теги через Discovery API.

В разделе [Пример запроса](#example-query) показаны некоторые поля, которые можно запрашивать у объекта `tags`. Полная схема со всеми доступными для запроса полями приведена в разделе [Поля](#fields).
 

### Пример запроса {#example-query}

Вы можете использовать `environmentId`, чтобы получить имена всех тегов в вашей среде:

```graphql
query {
  environment(id: 834) {
    applied {
      tags {
        name
      }
    }
  }
}
```
