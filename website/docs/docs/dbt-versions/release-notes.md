Примечания к выпускам <Constant name="dbt" /> с описанием недавних и более ранних изменений. Примечания к выпускам относятся к одной из следующих категорий:

- **Новое:** Новые продукты и функции
- **Улучшение:** Улучшение производительности и функций
- **Исправление:** Исправления ошибок и безопасности
- **Изменение поведения:** Изменение существующего поведения, которое не подходит под другие категории, например, устаревание функций или изменения настроек по умолчанию

Примечания к выпускам сгруппированы по месяцам для мультитенантных сред и сред в виртуальном частном облаке (VPC). <span><img src="/img/fontawesome/rss.svg" alt="RSS" className="rss-icon" />Подпишитесь на обновления примечаний к выпускам через [RSS](https://docs.getdbt.com/feeds/release-notes-rss.xml), [Atom](https://docs.getdbt.com/feeds/release-notes-atom.xml) или [JSON Feed](https://docs.getdbt.com/feeds/release-notes-rss.json).</span>

Об обновлениях <Constant name="fusion_engine" /> см. в [журнале изменений v2](https://github.com/dbt-labs/dbt/blob/main/CHANGELOG-dbt.md).

## Ноябрь 2026

- **Новое:** Удалённый сервер dbt MCP теперь доступен в [Databricks Marketplace](https://marketplace.databricks.com/details/6d83d4e0-5279-47b7-831c-3cb90a82ecb3/dbt-Labs_dbt-MCP). Установите его за несколько шагов, чтобы работать с проектом dbt из Databricks. См. [Интеграция Databricks с dbt MCP](/docs/dbt-ai/integrate-mcp-databricks).
- **Новое:** В <Constant name="wizard" /> Desktop можно редактировать существующие текстовые файлы в [Explorer](/docs/dbt-ai/wizard-desktop-use). Выберите **Save** или нажмите <kbd>Cmd</kbd>/<kbd>Ctrl</kbd> + <kbd>S</kbd>. Изменения сохраняются в отдельной копии проекта, а не в исходных файлах; несохранённые черновики остаются доступными после перехода в другой раздел или перезапуска.
- **Новое:** В <Constant name="wizard" /> Desktop можно переключаться между локальными профилями dbt и <Constant name="platform_cli" /> через меню подключения. <Constant name="wizard" /> запоминает ваш выбор, в том числе для проектов, связанных с <Constant name="dbt_platform" />.
- **Новое:** В представлении связей <Constant name="wizard" /> Desktop щёлкните модель правой кнопкой мыши, чтобы скопировать её имя, добавить её в чат, открыть её код или просмотреть различия. Доступные действия зависят от модели и текущего представления.
- **Новое:** Используйте Claude Haiku 5.5 и Claude Sonnet 5.5 через Databricks в <Constant name="wizard" />.
- **Улучшение:** В <Constant name="wizard" /> Desktop карточки с несколькими вопросами теперь открываются как одна карточка с постраничной навигацией. Можно вернуться назад, чтобы изменить ответы, и отправлять ответы с выбором вариантов с помощью более понятных встроенных элементов управления.
- **Улучшение:** В <Constant name="wizard" /> Desktop вкладка **Checks** в Inspector теперь называется **CI checks**, чтобы её было проще отличить от [проверок dbt](/docs/build/checks).
- **Исправление:** Выход из учётной записи ИИ-модели в <Constant name="wizard" /> Desktop больше не переключает вас на другую учётную запись. Выберите замену или выйдите без переключения. Другие учётные записи, в которые вы вошли, по-прежнему работают для вашего профиля и инструментов dbt.
- **Исправление:** Если провайдерам dbt AI требуется учётная запись, чат и средство выбора модели теперь сообщают, чего не хватает, и открывают средство выбора учётной записи вместо общей ошибки провайдера.
- **Исправление:** Валидация <Constant name="wizard" /> теперь работает с моделями Azure, Snowflake, Gemini и Databricks.
- **Исправление:** При неудачном сохранении в Explorer в <Constant name="wizard" /> Desktop черновик сохраняется, а успешное сохранение больше не перезаписывает изменения, внесённые вне <Constant name="wizard" />. Существующие чаты также продолжают работать после переключения сред.
- **Исправление:** <Constant name="wizard" /> больше не добавляет посторонний файл в новые среды или ваши коммиты. Создание и восстановление сред также работает в репозиториях, где этот файл уже отслеживается.
- **Исправление:** Когда <Constant name="wizard" /> подготавливает валидацию, критические ошибки <Constant name="platform_cli" /> теперь отображаются в виде понятных сообщений, а не необработанного JSON.
- **Исправление:** Граф связей в <Constant name="wizard" /> Desktop больше не смещается при обновлении проекта, а действия с моделями и контекстные меню работают надёжнее.
- **Новое:** <Constant name="wizard" /> теперь автоматически переключается на AWS Bedrock при сбое провайдера ИИ-моделей (OpenAI, Anthropic или Fireworks), чтобы вы могли продолжить работу. Доступно для учётных записей <Constant name="dbt_platform" />, размещённых в AWS и использующих модели dbt <Term id="managed" />. Подробнее см. в разделе [автоматическое резервирование при сбоях](/docs/dbt-ai/pricing-billing/overview#automatic-backup-during-outages).
- **Улучшение:** Таблица [**Marts**](/docs/explore/explore-projects#catalog-overview) на главной странице проекта в Catalog теперь по умолчанию показывает 20 строк на странице вместо 5. В раскрывающемся списке размера страницы появился вариант **20 Rows**, позволяющий просматривать список с меньшим числом переключений страниц.
- **Улучшение:** [API назначения пользователя в группы](/dbt-cloud/api-v3?version=2#/operations/Assign%20User%20to%20Groups) (`POST /api/v3/accounts/{account_id}/assign-groups/`) теперь принимает `add_group_ids` и `remove_group_ids`. Используйте эти поля, чтобы добавлять пользователя в группы или удалять его из групп, не заменяя весь список его групп. Передача `desired_group_ids` по-прежнему заменяет полный список.
- **Улучшение:** [Удалённый MCP](/docs/dbt-ai/setup-remote-mcp#permissions) теперь проверяет разрешения для каждого вызова инструмента применительно к целевому проекту, среде, заданию или запуску. Это относится к OAuth, персональным токенам доступа (PAT) и сервисным токенам. Набор разрешений `Developer` больше не требуется только для подключения. Сервисные токены также могут использовать `text_to_sql` для генерации SQL, но выполнение SQL через `execute_sql` по-прежнему требует OAuth или PAT.
- **Исправление:** В [Discovery API](/docs/dbt-apis/discovery-api) список родительских моделей раньше не включал модели из другого проекта ([Mesh](/docs/mesh/about-mesh)). Теперь эти родительские модели включены. В графе связей они уже отображались.
- **Исправление:** Если в аккаунте было более 1000 групп, некоторые назначенные пользователю [группы](/docs/platform/manage-access/about-user-access#groups) отсутствовали в представлении сведений о пользователе. Теперь все назначенные группы отображаются отмеченными. Сохранение через `POST /api/v3/accounts/{id}/assign-groups/` также сохраняет полный список групп.
- **Исправление:** Создание или обновление [ограничения по IP](/docs/platform/secure/ip-restrictions) с отсутствующим или недопустимым `type` теперь возвращает ошибку 400 (некорректный запрос) и сообщение с описанием проблемы вместо серверной ошибки 500. Отсутствующее `name` также отклоняется с ошибкой 400. До этого исправления dbt сохранял отсутствующее имя как слово None.
- **Исправление:** Аккаунты с тарифом на основе использования теперь могут завершить переход на [Starter](/docs/platform/billing/plans-and-billing#starter-plan-billing) без бесконечного индикатора загрузки при оформлении оплаты. Кнопка покупки остаётся доступной, если карта уже сохранена.
- **Изменение поведения:** Запуски dbt v2 в <Constant name="studio_ide" /> теперь используют значение [`threads`](/docs/running-a-dbt-project/using-threads) из ваших [учётных данных пользователя](/docs/dbt-platform-environments#set-user-credentials) вместо значения dbt v2 по умолчанию (например, 48 для Snowflake). Это изменение также применяется к запускам Canvas. Задания, запуски dbt v1 и функции редактора, такие как автодополнение, не изменились.
- **Изменение поведения:** Вызовы удалённого MCP без необходимых разрешений теперь могут завершаться ошибкой раньше, а при недопустимых аргументах или конфликтующем выборе проекта и среды возвращаются более понятные ошибки. Если вызов завершился ошибкой, проверьте разрешения на ресурс и настроенные идентификаторы. За помощью обратитесь к разделу [устранение неполадок удалённого MCP](/docs/dbt-ai/mcp-troubleshooting#troubleshooting).
- **Новое**: Пользователи с доступом только для чтения могут запрашивать метрики через [удалённый MCP](/docs/dbt-ai/setup-remote-mcp#read-only-users-and-warehouse-credentials), используя общие [учётные данные для аналитики](/docs/platform/wizard-read-only-users#set-up-analytics-credentials), которые должен настроить администратор. 

## Октябрь 2026

- **Новое:** <Constant name="wizard" /> Desktop теперь доступен в публичной бета-версии. [Скачайте приложение](/docs/dbt-ai/wizard-desktop#install-wizard-desktop) для macOS, Windows или Linux и начните первый сеанс.
- **Новое:** Если ваш GitHub Enterprise Server доступен только через частное подключение (PrivateLink), теперь это подключение можно сохранить в приложении GitHub. Укажите `private_link_endpoint_id` при создании или обновлении приложения через API, и dbt направит подключение через вашу частную сеть.
- **Новое:** **Фильтрация таблицы времени выполнения моделей:** На вкладке Model timing теперь можно фильтровать [Resource details](/docs/deploy/run-visibility#resource-details), чтобы находить причины замедления запуска. Используйте фильтр **Est. critical path**, чтобы показать только ресурсы в самой длинной цепочке зависимых ресурсов, определяющей минимальную продолжительность запуска (Yes), или все остальные ресурсы (No). Используйте фильтр типа ресурса, чтобы ограничить список типами **Model**, **Test**, **Snapshot** или **Exposure**. Поиск по имени по-прежнему доступен.
- **Новое:** Задайте [`allow_jinja_file_extensions`](/reference/global-configs/behavior-flags/allow_jinja_file_extensions) в конфигурации проекта, чтобы dbt читал файлы с дополнительным расширением Jinja, например `model.sql.j2` или `doc.md.j2`. Jinja — язык шаблонов, который dbt уже использует внутри файлов SQL и Markdown.
- **Новое:** На [главной вкладке](/docs/platform/wizard-home) <Constant name="wizard" /> открытая беседа отражается в URL браузера. Можно добавить беседу в закладки и снова открыть её по URL.
- **Улучшение:** Если проект может использовать dbt v2, но у вас нет разрешения выбрать эту версию, варианты dbt v2 остаются видимыми, но недоступными в меню версий среды, задания и разработки. В подсказке указано, что выбрать dbt v2 должен Account Admin или [v2 Migration Admin](/docs/platform/manage-access/enterprise-permissions#v2-migration-admin).
- **Улучшение:** Если [график использования](/docs/platform/billing/how-pricing-works#viewing-usage-in-the-product) не загружается или не обновляется, вы увидите сообщение и кнопку **Retry**. Это относится к графику числа построенных моделей за месяц на странице **Project home** и графику основных заданий на странице **Environment**. Ранее загруженный график сохраняет последние значения и показывает время их обновления, пока выполняется повторная попытка.
- **Улучшение:** В Studio в разделе [User development settings](/docs/dbt-versions/upgrade-dbt-platform-version#override-dbt-version) вариант **v2 Stable** больше не имеет метки **Preview**. dbt v2 общедоступен.
- **Улучшение:** В расширении dbt для VS Code можно перетащить край заголовка столбца на панели результатов запроса, чтобы увеличить или уменьшить его ширину.
- **Улучшение:** **Больше времени на подтверждение электронной почты**: Короткие коды подтверждения электронной почты теперь действуют 10 минут вместо 5, оставляя больше времени на подтверждение учётной записи.
- **Исправление:** Если при регистрации используется адрес электронной почты, для которого уже есть учётная запись, в том числе при двух одновременных регистрациях с этим адресом, dbt показывает страницу с сообщением, что адрес уже занят. Общая страница ошибки больше не появляется.
- **Исправление:** Запрос с недопустимым значением теперь возвращает понятную ошибку вместо серверной. Неподдерживаемое значение `order_by` в эндпоинтах списков версии 3, а также отрицательные или слишком большие `limit` или `offset` в эндпоинтах списков версии 2 возвращают ошибку 400 (некорректный запрос). Создание проекта через `POST /api/v2/accounts/{id}/projects/` также возвращает ошибку 400, если `type` не является текстом. Получение времени выполнения через `GET /api/v3/accounts/:id/projects/:id/runs/:id/timing/` возвращает 404 (не найдено), если запуск не относится к аккаунту или проекту из URL.
- **Исправление:** В <Constant name="studio_ide" /> модель [ephemeral](/docs/build/materializations#ephemeral) — это модель, которая не создаётся как отдельная таблица или представление. Такие модели отсутствовали в списке результатов команды, поэтому вкладки **Error**, **Warn**, **Skip**, **Reused** или **Pass** могли показывать количество без строк. Теперь они отображаются на соответствующей вкладке вместе с другими моделями.
- **Исправление:** Откройте запуск задания, выберите шаг и откройте **System logs**. Теперь эта вкладка включает логи ваших моделей, позволяя разбирать ошибки запуска в одном месте.
- **Исправление:** [`dbt fmt`](/reference/commands/lint#dbt-format) больше не сдвигает тег Jinja влево, если та же строка заканчивается SQL-комментарием. Также теперь используется стабильный отступ для тегов Jinja внутри цикла `for` и блока `{% if %}...{%- else -%}`, условие которого запрашивает информацию о хранилище, например столбцы таблицы. Повторный запуск `dbt fmt` больше не меняет эти строки.
- **Изменение поведения:** Вкладка **System logs** на шаге запуска раньше показывала только системные сообщения. Теперь она показывает все логи этого шага, включая логи моделей. Если вы использовали эту вкладку только для системных сообщений, теперь строк в ней будет больше.
- **Изменение поведения:** В dbt v2 переименована переменная выбора ИИ-провайдера и две переменные записи [информационной схемы](/docs/build/dbt-information-schema#generating-the-information-schema) (локальной копии метаданных проекта, доступной для запросов). Если вы задаёте `DBT_AI_PROVIDER`, замените её на [`DBT_ENGINE_AI_PROVIDER`](/docs/dbt-ai/package-skills#set-the-ai_provider-flag). Если вы задаёте `DBT_GENERATE_INFO_SCHEMA` или `DBT_INFO_SCHEMA_DIR`, замените их на `DBT_ENGINE_GENERATE_INFO_SCHEMA` и `DBT_ENGINE_INFO_SCHEMA_DIR`. Флаги командной строки для этих параметров не изменились. Обновите переменные везде, где они задаются, включая непрерывную интеграцию (CI).
- **Новое:** Теперь можно [направлять межпроектные `ref()`](/docs/mesh/govern/project-dependencies#route-environments-across-projects) в конкретную вышестоящую среду, например Staging, а не только в среду Production или Staging по умолчанию.
- **Новое:** В <Constant name="wizard" /> Desktop можно искать по текущему чату и переходить между совпадениями, включая текст в блоках кода.
- **Новое:** В <Constant name="wizard" /> Desktop используйте `/new`, `/clear` и `/rename` для управления беседами. `/new` принимает необязательный начальный запрос и работает во время формирования другого ответа.
- **Новое:** В <Constant name="wizard" /> Desktop можно одним подтверждённым действием отменить все незакоммиченные изменения и удалить новые файлы. Файлы с конфликтами не затрагиваются.
- **Новое:** В <Constant name="wizard" /> Desktop можно включить автоматические фоновые обновления, выбрать канал Stable или Unstable в настройках **General** и перезапустить приложение, когда обновление готово. См. [Обновление приложения](/docs/dbt-ai/wizard-desktop#update-the-app).
- **Улучшение:** Карточки вопросов в <Constant name="wizard" /> Desktop теперь позволяют отвечать на несколько вопросов, писать собственный ответ или пропускать вопрос. Пока вопросы ожидают ответа, можно также писать в поле ввода; для конфиденциальных ответов предусмотрены маскированные поля.
- **Улучшение:** В <Constant name="wizard" /> Desktop раздел **Changes** и целевая ветка теперь следуют базовой ветке открытого pull request.
- **Улучшение:** В <Constant name="wizard" /> Desktop разверните **Show error details**, чтобы узнать причину неудачного ответа, включая ошибки провайдера и лимиты расходов.
- **Исправление:** <Constant name="wizard" /> Desktop теперь по умолчанию использует вход через браузер для подписок OpenAI, в том числе для рабочих пространств, где вход по коду устройства отключён. Просроченные или отозванные учётные данные больше не блокируют запуск; инструкции по повторному подключению стали понятнее.
- **Исправление:** <Constant name="wizard" /> Desktop поддерживает актуальность данных поиска моделей, связей и метрик после редактирования файлов или запуска dbt вне <Constant name="wizard" />.
- **Исправление:** Валидация <Constant name="wizard" /> теперь пропускает запуски, если в области проверки нет изменённых моделей dbt, и объясняет причину.
- **Исправление:** <Constant name="wizard" /> Desktop теперь показывает более понятные запросы о владельце и доверии для общих репозиториев. Также можно запускать чаты и терминалы в доверенных репозиториях другого пользователя, в том числе в подсистеме Windows для Linux (WSL).
- **Исправление:** Запросы на одобрение действий субагентов в <Constant name="wizard" /> Desktop теперь появляются в соответствующем чате и содержат имя запрашивающего агента.
