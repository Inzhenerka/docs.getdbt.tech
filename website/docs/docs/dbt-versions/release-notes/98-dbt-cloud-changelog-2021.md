#### Новые продукты и возможности
- Теперь вы можете добавлять переменные окружения в свой проект <Constant name="dbt" />. Почему это важно? Переменные окружения — один из основных строительных блоков проекта dbt, который до сих пор был доступен только в <Constant name="core" />. Они позволяют решать множество задач: клонировать приватные пакеты, ограничивать объём данных, обрабатываемых в средах разработки, менять источники данных в зависимости от среды и многое другое. Подробнее о переменных окружения читайте в нашей [статье в блоге](https://blog.getdbt.com/introducing-environment-variables-in-dbt-cloud/) или [документации](/docs/build/environment-variables).

## dbt Cloud v1.1.37 (13 октября 2021) {#dbt-cloud-v1137-october-13-2021}
dbt v0.21 теперь доступен в dbt Cloud. Главное изменение этого релиза — появление команды `dbt build`. `dbt build` логически выполняет всё, что вы хотите сделать в своём DAG: запускает модели, выполняет тесты, снапшоты и сиды. Он делает это по ресурсам, слева направо по вашему DAG. `dbt build` — это осознанно «мнение‑ориентированная» задача. Это кульминация всего, что мы построили: запуск моделей с устойчивыми <Term id="materialization">материализациями</Term>, приоритизация качества данных с помощью тестов, обновление фикстур через seeds, захват медленно изменяющихся измерений с помощью snapshots. Попробуйте!

## dbt Cloud v1.1.32 (4 августа 2021 г.)
Metadata API теперь общедоступен (GA)! Когда <Constant name="dbt" /> выполняет определённые команды, такие как run, test, seed и другие, dbt генерирует метаданные в виде [артефактов](/reference/artifacts/dbt-artifacts). Эти артефакты содержат множество сведений о настройке проекта, времени выполнения, результатах тестов, скомпилированном SQL и многом другом. Теперь <Constant name="dbt" /> предоставляет GraphQL API, который поддерживает произвольные запросы к этим артефактам, поэтому вы можете получать нужные метаданные практически мгновенно.

#### Новые продукты и возможности
- Metadata API — первый компонент нашего набора продуктов для работы с метаданными. Подробнее об использовании Metadata API читайте [здесь](/docs/dbt-apis/discovery-api).
- Клиентам dbt Enterprise, использующим GitHub, теперь доступно улучшенное <Term id="grain">детализированное</Term> управление доступом к проектам dbt. dbt будет применять права доступа git для каждого разработчика, чтобы политики чтения и записи, заданные в GitHub, действовали и в IDE.
