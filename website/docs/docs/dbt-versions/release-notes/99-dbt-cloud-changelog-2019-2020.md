Добро пожаловать в журнал изменений приложения <Constant name="dbt" /> за 2019 и 2020 годы! В этом журнале вы найдёте основные сведения о новых возможностях, исправлениях и улучшениях за этот период.

## dbt Cloud v1.1.16 (23 декабря 2020) {#dbt-cloud-v1116-december-23-2020}

В этом выпуске добавлена предварительная поддержка Databricks Spark в <Constant name="dbt" />
и два новых набора разрешений для учетных записей Enterprise.

#### Улучшения {#enhancements}

- Добавлена предварительная поддержка Databricks Spark
- Добавлены два новых набора разрешений Enterprise: Account Viewer и Project Creator

#### Исправления {#fixed}

- Улучшена инфраструктура логирования для логов dbt run
- Исправлены ошибки логирования SSH-туннелей


## dbt Cloud v1.1.15 (10 декабря 2020) {#dbt-cloud-v1115-december-10-2020}

В этом релизе есть много интересного для обсуждения: на этой неделе многое сошлось воедино! Большой интерес вызвало добавление Spark в семейство подключений, а также исправление ряда давних ошибок.

#### Улучшения {#enhancements-1}

- Добавлен Spark как вариант при настройке базы данных

#### Исправления {#fixed-1}

- Исправлена сложная ошибка, из-за которой одному адресу электронной почты могло соответствовать несколько учетных записей пользователей
- Исправлена маршрутизация React-страницы setup-connection
- Логика выбора групп отделена от типов лицензий и названий групп
- Добавлена обработка ошибок JSON при разборе тела запросов v1/v2
- Добавлена корректная обработка AuthForbidden и AuthCancelled без возврата ошибок 500
- Исправлена регрессия, связанная с индикатором загрузки <Constant name="studio_ide" />


## dbt Cloud v1.1.14 (25 ноября 2020) {#dbt-cloud-v1114-november-25-2020}

В этом релизе появилось несколько новых интеграционных возможностей, в частности OAuth для BigQuery и доработки SparkAdapter. Также мы внесли ряд улучшений для удобства работы и заложили основу для будущих возможностей, уделив особое внимание нашим любимым пользователям <Constant name="studio_ide" />, а ещё улучшили передачу данных для наблюдаемости в системы управления логами и мониторинга использования API.

#### Улучшения {#enhancements-2}

- Обновлён allowlist IP-адресов
- Пользователь может использовать OAuth для BigQuery в учётных данных профиля
- Добавлены backend-модели, мапперы и сервисы SparkAdapter
- Добавлена интеграция BigQuery OAuth
- Добавлен индекс базы данных для owner_thread_id

#### Исправления {#fixed-2}

- Исправлен уровень ошибок для POST /run
- Исправлена ошибка, при которой в dbt run передавался неверный аргумент
- Логирование необработанных ошибок в менеджере контекста переменных окружения
- Удалены разрешения на настройки аккаунта для пользовательских интеграций


## dbt Cloud v1.1.13 (12 ноября 2020) {#dbt-cloud-v1113-november-12-2020}

В этом выпуске добавлена поддержка запуска заданий с переопределёнными атрибутами через
эндпоинт API [triggerRun](/dbt-cloud/api-v2#). Кроме того,
исправлен ряд ошибок и повышена производительность.

#### Улучшения {#enhancements-3}

- Улучшена обработка ошибок для длительных запросов в <Constant name="studio_ide" />
- Добавлено кэширование клиента S3 для ускорения скачивания логов запланированных запусков
- Добавлена поддержка запуска заданий [с переопределением атрибутов через API](/dbt-cloud/api-v2#)
- Уточнён текст о переходе на более высокий тариф на странице оплаты

#### Исправления {#fixed-3}

- Эндпоинт GitLab groups теперь возвращает все группы и подгруппы
- Поддержка retry-конфигураций BigQuery со значением 0
- Предотвращён краш Web IDE после запуска некорректной команды dbt
- Дополнительная очистка логов для фильтрации краткоживущих git-учётных данных
- Исправлена старая миграция, чтобы поле auth_url могло быть NULL
- Поддержка путей в URL GitLab-инстанса
- Исправлен URL запроса auth token в OAuth-флоу GitLab

## dbt Cloud v1.1.9 (1 октября 2020) {#dbt-cloud-v119-october-1-2020}

Этот релиз добавляет возможность для администраторов на Enterprise-плане настраивать
права Role Based Access Control, применяемые к проектам в аккаунте.
Кроме того, откладывание выполнения заданий теперь доступно за feature flag,
а также выпущен ряд исправлений и улучшений.

#### Улучшения {#enhancements-7}

- Добавлена версия <Constant name="dbt" /> на боковой панели навигации
- Добавлены интерфейсы просмотра, создания и изменения разрешений групп RBAC
- Добавлены модальные окна обработки ошибок персональной аутентификации Git для <Constant name="studio_ide" />
- Добавлены запросы на разработку в представления бэкенда
- Реализовано отложенное выполнение заданий
- Добавлена поддержка dbt v0.18.1b2

#### Исправления {#fixed-7}

- Исправлена ситуация, при которой взаимодействие с кнопкой обновления <Constant name="studio_ide" /> приводило к тому, что файл index.lock оставался в файловой системе <Constant name="studio_ide" />
- Добавлена проверка URL PR на попытки XSS-атак
- Устранены несоответствия в RBAC
- Исправлена ошибка, из-за которой пользователи не могли обновить свой пароль <Constant name="dbt" /> в приложении
- Исправлено применение разрешений пользователя в нескольких аккаунтах после аутентификации через SSO
- Google API: по умолчанию используется общая конечная точка API с возможностью переопределения
- Исправлено отсутствие переменной email в отладочных логах GSuite
- Добавлено завершение сеанса <Constant name="studio_ide" /> при переключении между проектами
