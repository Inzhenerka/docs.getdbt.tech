# Редактирование и создание моделей dbt

<p style={{ color: '#717d7d', fontSize: '1.1em' }}>
Откройте <Constant name="canvas" /> и используйте его для создания и редактирования моделей dbt в визуальном интерфейсе с поддержкой перетаскивания.
</p>

## Доступ к Canvas {#access-canvas}

Перед тем как открыть редактор, убедитесь, что у вас уже настроен проект <Constant name="dbt" />. Это включает репозиторий <Constant name="git" />, подключение к платформе данных, среды и учетные данные пользователя. Если всё это ещё не настроено, обратитесь к администратору <Constant name="dbt" />.

Открыть **<Constant name="canvas" />** можно в любое время из меню слева.

## Создание модели {#create-a-model}

Чтобы создать SQL-модель dbt, нажмите **Create a new model** и выполните следующие действия. Обратите внимание: в <Constant name="canvas" /> нельзя создавать модели источников. Для этого необходим запуск в производственной среде с уже созданными источниками.

1. Перетащите [оператор](/docs/platform/canvas-interface#operators) с панели операторов на рабочую область.
2. Нажмите на оператор, чтобы открыть панель его настройки.
3. Просмотрите вкладки **Output** и **SQL Code**. 
	- У каждого оператора есть вкладка Output, на которой можно предварительно просмотреть данные из настроенного узла.
	- На вкладке Code отображается SQL-код, сгенерированный на основе конфигурации узла. Используйте её, чтобы просмотреть SQL-код, соответствующий настройкам вашей визуальной модели.
4. Соедините операторы: перетащите курсор от начальной точки «+» одного оператора к другим операторам, с которыми хотите его связать. При этом должна появиться соединительная линия. 
	- Это позволит данным проходить из исходной таблицы через настроенные вами преобразования к конечному результату.
5. Продолжайте создавать модель dbt и обязательно проверяйте результат на вкладке **Output**.

## Редактирование существующей модели
Чтобы отредактировать существующую модель: 
1. Перейдите в рабочую область <Constant name="canvas" />.
2. Нажмите **+Add** на верхней панели навигации.
3. Нажмите **Edit existing model**.

После этого вы сможете выбрать модель, которую хотите отредактировать.

<Lightbox src="/img/docs/dbt-platform/canvas/edit-model.png" width="90%" title="Отредактируйте модель с помощью кнопки «Edit a model»." />

## Загрузка данных в Canvas {#upload-data-to-canvas}

Вы можете загрузить CSV-файл с исходными данными для создания модели непосредственно из <Constant name="canvas" />:

1. Нажмите **+Add**. 
2. Выберите **Upload CSV source**.
3. Перетащите файл в область холста или нажмите **Upload**, чтобы выбрать его через файловый менеджер.

Данные будут загружены в ваше хранилище данных в виде новой таблицы в схеме разработчика. Таблица будет иметь префикс `VE_UPLOADS_`.

В окне canvas создаются оператор источника и базовая SQL-модель, которую можно настроить под свои задачи. Теперь вы можете работать с этими данными как в <Constant name="canvas" />, так и в <Constant name="studio_ide" />.

## Тестирование и документация {#test-and-document}

Тестирование и документирование моделей — важная часть процесса разработки.  

Следите за обновлениями! Совсем скоро вы сможете тестировать и документировать свои модели dbt в <Constant name="canvas" />. Это позволит поддерживать высокое качество данных и чётко описывать, как следует использовать ваши модели.
