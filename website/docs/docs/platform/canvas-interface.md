# Навигация по интерфейсу

<p style={{ color: '#717d7d', fontSize: '1.1em' }}>

Интерфейс <Constant name="canvas" /> включает панель операторов, операторы, рабочую область и другие элементы, которые позволяют получать и преобразовывать данные, легко создавая модели dbt с помощью перетаскивания в <Constant name="dbt" />.

</p>

На этой странице приведены подробные определения и термины для элементов пользовательского интерфейса, которые помогут вам легко ориентироваться в <Constant name="canvas" />.

Интерфейс <Constant name="canvas" /> состоит из следующих элементов:

- **Панели навигации** &mdash; Верхняя и левая панели навигации содержат элементы для переключения между моделями в рабочем пространстве, открытия существующих и создания новых моделей, загрузки данных CSV, предварительного просмотра данных и запусков, а также просмотра полезных сочетаний клавиш.
- **Панель операторов** &mdash; Расположена в верхней части рабочей области и содержит все доступные категории узлов, а также инструменты для разработки:
	- **Input:** Исходные модели и данные
	- **Transform:** Инструменты преобразования данных
	- **Output:** Настройки выходной модели
	- **[dbt Copilot](/docs/platform/build-canvas-copilot):** Инструменты ИИ для быстрой и эффективной разработки
	- **SQL:** Просмотр скомпилированного SQL-кода готовой модели
- **Операторы** &mdash; Плитки, которые предоставляют исходные данные, выполняют определённые преобразования и задают настройки (например, модель, соединение, агрегацию, фильтрацию и т. д.). Используйте соединители, чтобы связывать операторы и выстраивать полный конвейер преобразования данных. 
- **Рабочая область** &mdash; Основное пространство под панелью узлов. В рабочей области можно легко создавать и изменять модели с помощью перетаскивания.
- **Панель настройки** &mdash; У каждого оператора есть панель настройки, которая открывается при нажатии на него. Она позволяет настроить оператор, просмотреть текущую модель, предварительно просмотреть изменения в таблице, посмотреть SQL-код узла и удалить оператор.

## Операторы {#operators}

Панель операторов над canvas содержит различные операторы трансформации, доступные для использования. Каждый оператор применяется для настройки или выполнения конкретных задач, например добавления фильтров или объединения моделей, путём перетаскивания оператора на canvas. Вы можете соединять операторы с помощью линий‑коннекторов, формируя полноценную модель для трансформации данных.

<Lightbox src="/img/docs/dbt-platform/canvas/operators.png" width="90%" title="Используйте панель инструментов операторов для выполнения различных операций преобразования." />

Доступны следующие операторы:
#### Ввод {#input}

Операторы ввода настраивают исходные данные:
- **Model explorer**: Выбор модели и колонок, которые вы хотите использовать.

#### Трансформация {#transform}

Операторы преобразования позволяют изменять структуру и содержимое данных:
- **Join**: Задайте условия соединения и выберите столбцы из обеих таблиц.
- **Union:** Выполните `UNION`, чтобы удалить дубликаты, или `UNION ALL`, чтобы сохранить их.
- **Formula**: Добавьте формулу для создания нового столбца. Используйте [dbt Copilot](/docs/platform/build-canvas-copilot) для помощи в генерации SQL.
- **Aggregate**: Укажите функции агрегации и столбцы, к которым они применяются. Чтобы сгенерировать SQL по запросу на естественном языке, нажмите значок вопросительного знака (?) и воспользуйтесь [dbt Copilot](/docs/platform/build-canvas-copilot).
- **Pivot:** Выберите столбец и значения для создания сводной таблицы.
- **Limit**: Задайте максимальное количество возвращаемых строк.  
- **Order**: Выберите столбцы для сортировки и порядок сортировки.
- **Filter**: Задайте условия фильтрации данных.	
- **Rename:** Задайте собственные псевдонимы для столбцов.

#### Модель вывода {#output-model}

Операторы вывода настраивают имя и расположение трансформированных данных:
- **Output model**: Итоговый трансформированный датасет, создаваемый dbt‑моделью. Можно использовать только одну output‑модель.

При клике на любой оператор открывается панель конфигурации. Она позволяет настраивать оператор, просматривать текущую модель, выполнять предпросмотр изменений, смотреть SQL‑код узла и удалять оператор.

<Lightbox src="/img/docs/dbt-platform/canvas/canvas.png" width="90%" title="Интерфейс Canvas, содержащий панель инструментов узлов и рабочую область." />

Если у вас есть предложения по дополнительным операторам, которые могли бы быть полезны, мы будем рады их услышать. Пожалуйста, свяжитесь с вашей командой dbt Labs и поделитесь своими идеями.

## Оператор Canvas {#canvas}

<Constant name="canvas" /> предлагает удобный интерфейс с перетаскиванием элементов для создания и изменения SQL-моделей dbt. Это своего рода цифровая доска, на которой удобно просматривать и предоставлять достоверные данные. Используйте этот интерфейс, чтобы:

- Перетаскивать операторы для создания и настройки моделей
- Генерировать SQL-код с помощью [dbt Copilot](/docs/platform/build-canvas-copilot)
- Увеличивать или уменьшать масштаб для более наглядного представления
- Управлять версиями моделей dbt
- [Скоро] Тестировать и документировать созданные модели

<Lightbox src="/img/docs/dbt-platform/canvas/operators.png" width="90%" title="Панель операторов позволяет выбирать различные узлы для настройки или выполнения определённых задач, например добавления фильтров или объединения моделей." />

### Коннектор {#connector}

Коннекторы позволяют соединять операторы для создания dbt‑моделей. После добавления операторов на canvas:
- Наведите курсор на знак «+» рядом с оператором и нажмите на него.
- Перетащите курсор от стартовой точки «+» оператора к другому узлу, который вы хотите соединить. В результате появится линия‑коннектор.
- Например, чтобы создать join, подключите один оператор к «L» (Left), а другой — к «R» (Right). Точки подключения расположены слева от оператора, что упрощает перетаскивание коннекторов.

<Lightbox src="/img/docs/dbt-platform/canvas/connector.png" width="100%" title="Нажмите и перетащите курсор, чтобы соединить операторы." />

## Панель конфигурации {#configuration-panel}

У каждого оператора есть боковая панель конфигурации, которая открывается при клике на него. Эта панель позволяет настраивать оператор, просматривать текущую модель, выполнять предпросмотр изменений, смотреть SQL‑код оператора и удалять его.

Боковая панель настройки содержит следующие элементы:
- Вкладка Configure &mdash; В этом разделе можно настроить оператор в соответствии с вашими требованиями, например использовать [dbt Copilot](/docs/platform/build-canvas-copilot) для генерации SQL.
- Вкладка Input &mdash; В этом разделе можно просмотреть данные текущей исходной таблицы. Недоступна для операторов моделей.
- Вкладка Output &mdash; В этом разделе можно предварительно просмотреть данные изменённой исходной модели.
- Code &mdash; В этом разделе можно просмотреть SQL-код, лежащий в основе преобразования данных.

<Lightbox src="/img/docs/dbt-platform/canvas/config-panel.png" width="90%" title="Удобный интерфейс холста с поддержкой перетаскивания, позволяющий создавать или изменять SQL-модели dbt." />
