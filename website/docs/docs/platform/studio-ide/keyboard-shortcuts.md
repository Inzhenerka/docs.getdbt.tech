Cloud IDE предоставляет горячие клавиши, функции и советы по разработке, которые помогут вам работать быстрее и быть более продуктивными.

<Constant name="studio_ide" /> предоставляет сочетания клавиш, функциональные возможности и советы по разработке, которые помогут вам работать быстрее и продуктивнее. 

Используйте эту страницу <Constant name="studio_ide" />, чтобы быстро находить справочную информацию о распространённых операциях.

| Описание сочетания клавиш | macOS | Windows |
|--------|----------------|------------------|
| Посмотреть полный список сочетаний клавиш редактора, которые помогают при разработке: добавление строчного комментария, изменение отображаемой ширины табуляции, сборка изменённых моделей, изменение размера шрифта редактора и многое другое.  | Fn-F1 | Fn-F1 |
| Выбрать файл для открытия. | Command-O | Control-O |
| Закрыть текущую активную вкладку редактора. | Option-W | Alt-W |
| Предварительно просмотреть код. | Command-Enter | Control-Enter |
| Скомпилировать код. | Command-Shift-Enter | Control-Shift-Enter |
| Показать список функций dbt в редакторе. | Введите два символа подчёркивания `__` | Введите два символа подчёркивания  `__` |
| Открыть палитру команд для вызова команд и действий dbt.  | Command-P / Command-Shift-P | Control-P / Control-Shift-P |
| Редактировать несколько строк одновременно, выделив их в редакторе. | Option-Click / Shift-Option-Command / Shift-Option-Click  | Alt-Click / Shift-Alt-Click |
| Открыть [**панель истории вызовов**](/docs/platform/studio-ide/ide-user-interface#invocation-history), расположенную в нижней части IDE.  | Control-backtick (или Control + `)  | Control-backtick (или Ctrl + `) | 
| Добавить блочный комментарий к выделенному коду. В SQL-файлах будет использоваться синтаксис Jinja `({# #})`, а не SQL `(/* */)`. | Shift-Option-A | Shift-Alt-A |
