# Многофакторная аутентификация {#multi-factor-authentication}

:::important

<Constant name="dbt" /> требует использования многофакторной аутентификации (MFA) для всех пользователей, которые входят с помощью имени пользователя и пароля. Если MFA не настроена, при входе вы увидите панель уведомлений с предложением настроить один из поддерживаемых методов. Если вы этого не сделаете, вам придётся настроить MFA при последующих входах, иначе вы не сможете получить доступ к <Constant name="dbt" />.

:::

<Constant name="dbt" /> предоставляет несколько вариантов многофакторной аутентификации (MFA), которая добавляет дополнительный уровень защиты при входе с помощью имени пользователя и пароля. MFA доступна во всех тарифных планах <Constant name="dbt" /> только для пользователей, которые входят с помощью имени пользователя и пароля. Доступны следующие методы MFA:

- SMS-код подтверждения  
    - В настоящее время поддерживаются только номера телефонов с кодом страны +1 Североамериканского плана нумерации (NANP).
- Приложение-аутентификатор
- Аппаратный ключ безопасности, совместимый с WebAuthn

## Конфигурация {#configuration}

Вы можете настроить только один из трех методов MFA для каждого пользователя. Эти методы включаются на уровне пользователя, а не на уровне аккаунта.

1. Перейдите в **Настройки аккаунта** и в разделе **Ваш профиль** нажмите **Пароль и безопасность**. Нажмите **Зарегистрировать** рядом с предпочтительным методом.
    
<Lightbox src="/img/docs/dbt-platform/mfa-enrollment.png" title="Список доступных методов регистрации MFA в dbt." />

Выберите следующие шаги в зависимости от вашего выбора метода регистрации:

<Expandable alt_header="Код подтверждения по SMS">

<Lightbox src="/img/docs/dbt-platform/sms-enter-phone.png" width="60%" title="Выбор номера телефона с раскрывающимся списком кодов стран." />

3. Вы получите SMS-сообщение с шестизначным кодом. Введите этот код в <Constant name="dbt" />.

<Lightbox src="/img/docs/dbt-platform/enter-code.png" width="60%" title="Введите шестизначный код." />

</Expandable>

<Expandable alt_header="Приложение-аутентификатор">

2. Откройте предпочитаемое приложение-аутентификатор (например, Google Authenticator) и отсканируйте QR-код.

<Lightbox src="/img/docs/dbt-platform/scan-qr.png" title="Пример QR-кода, созданного пользователем." />

3. Введите код для «dbt Labs: YOUR_EMAIL_ADDRESS» из приложения-аутентификатора в поле в <Constant name="dbt" />.

</Expandable>

<Expandable alt_header="Ключ безопасности, совместимый с Webauthn">

2. Следуйте инструкциям в модальном окне и нажмите **Использовать ключ безопасности**.

<Lightbox src="/img/docs/dbt-platform/create-security-key.png" title="Пример окна активации ключа безопасности." />

3. Отсканируйте QR-код или вставьте и активируйте ваш USB-ключ, чтобы начать процесс. Следуйте подсказкам на экране.

</Expandable>

4. Вам будет предоставлен резервный код доступа, сохраните его в безопасном месте. Этот ключ будет полезен, если метод MFA не сработает (например, потерян или сломан телефон).

## Восстановление аккаунта {#account-recovery}

При настройке MFA убедитесь, что вы храните коды восстановления в безопасном месте на случай, если ваш метод MFA не сработает. Если вы не можете получить доступ к своему аккаунту, обратитесь в [support@getdbt.com](mailto:support@getdbt.com) за дополнительной поддержкой. Возможно, вам придется создать новый аккаунт, если ваш аккаунт не удастся восстановить.

Если возможно, рекомендуется настроить несколько методов MFA, чтобы в случае сбоя одного из них у вас был резервный вариант.
