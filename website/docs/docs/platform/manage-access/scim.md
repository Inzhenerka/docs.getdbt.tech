# Настройка SCIM

Стандарт System for Cross-Domain Identity Management (SCIM) повышает безопасность пользовательских данных и упрощает управление жизненным циклом пользователей для администраторов и конечных пользователей, автоматизируя управление учетными записями и группами. Вы можете создавать или отключать учетные записи пользователей у своего поставщика удостоверений (IdP), а SCIM автоматически применит эти изменения в <Constant name="dbt" /> практически в реальном времени.

При настройке IdP ознакомьтесь с [ограничениями частоты запросов к API](/docs/dbt-apis/rate-limits), чтобы узнать о квотах на подготовку учетных записей через SCIM и правилах повторных запросов при получении ошибки `429`.

## Предварительные требования

Чтобы настроить SCIM в вашей среде <Constant name="dbt" />:
- У вас должен быть [тариф Enterprise или Enterprise+](https://www.getdbt.com/pricing).
- Вы должны использовать Okta или Entra ID в качестве поставщика SSO и подключить его к платформе dbt.
- У вас должны быть [разрешения](/docs/platform/manage-access/enterprise-permissions) на настройку параметров аккаунта в <Constant name="dbt_platform" /> и изменение настроек приложения в [Okta](https://help.okta.com/en-us/content/topics/security/administrators-admin-comparison.htm).
- Если у вас включены ограничения по IP-адресам, необходимо добавить [IP-адреса Okta](https://help.okta.com/en-us/content/topics/security/ip-address-allow-listing.htm) в список разрешенных. Если вы используете Entra ID с включенными ограничениями по IP-адресам, обратитесь к разделу [Сбой подготовки учетных записей через Azure SCIM из-за списка разрешенных IP-адресов](/docs/platform/manage-access/scim-faq) в ответах на часто задаваемые вопросы о SCIM.

### Поддерживаемые возможности

В настоящее время для SCIM поддерживаются следующие возможности:

- Создание и отключение учетных записей пользователей
- Обновление профилей пользователей
- Создание групп и управление ими
- Импорт групп и пользователей

При включении SCIM поведение следующих функций изменяется:
- Пользователи не добавляются в группы по умолчанию автоматически
- Действия вручную, такие как приглашение пользователей, обновление сведений о пользователях и изменение членства в группах, по умолчанию отключены
- Сопоставления групп SSO отключаются, а управление группами осуществляется через SCIM. Подробности см. в разделе [Продолжают ли действовать сопоставления групп SSO при включенном SCIM?](/docs/platform/manage-access/scim-faq).

Чтобы отменить эти изменения в работе функций при включенном SCIM, разрешите ручные обновления в настройках SCIM (не рекомендуется).

При создании учетных записей пользователей поддерживаются следующие атрибуты
- Имя пользователя
- Фамилия
- Имя

В пользовательском интерфейсе <Constant name="dbt" /> поддерживаются следующие IdP:
- [Настройка SCIM с Okta](/docs/platform/manage-access/scim-okta) (включая [управление лицензиями](/docs/platform/manage-access/scim-manage-user-licenses))
- [Настройка SCIM с Entra ID](/docs/platform/manage-access/scim-entra-id)

Если вашего IdP нет в списке, его можно подключить с помощью [API](/dbt-cloud/api-v3#/operations/Retrieve%20SCIM%20configuration) <Constant name="dbt" />.

## Настройка dbt {#set-up-dbt}

Чтобы получить необходимые параметры конфигурации <Constant name="dbt" /> для использования в Okta или Entra ID:

1. Перейдите в **Account settings** в <Constant name="dbt" />.
2. В разделе **Settings** нажмите **SSO & SCIM**.
3. Прокрутите настройки конфигурации SSO до конца и нажмите **Enable SCIM**.
    <Lightbox src="/img/docs/dbt-platform/access-control/enable-scim.png" width="60%" title="SCIM включен в настройках конфигурации." />
4. Сохраните значение поля **SCIM base URL** для использования на одном из следующих шагов.
5. Нажмите **Create SCIM token**.
    :::note
    В соответствии с рекомендациями по безопасности следует регулярно менять токены SCIM. Для этого выполните те же действия, что и при создании нового токена. Чтобы избежать перебоев в работе, не забудьте заменить токен в вашем IdP, прежде чем удалять старый токен в <Constant name="dbt" />.
    :::
6. Во всплывающем окне задайте токену имя, по которому его будет легко определить. Нажмите **Save**.
    <Lightbox src="/img/docs/dbt-platform/access-control/name-scim-token.png" width="60%" title="Задайте токену имя для его идентификации." />
7. Скопируйте токен и сохраните его в безопасном месте, поскольку _после закрытия окна он больше не будет доступен_. Если вы потеряете текущий токен, потребуется создать новый.
    <Lightbox src="/img/docs/dbt-platform/access-control/copy-scim-token.png" width="60%" title="Задайте токену имя для его идентификации." />
8. (Необязательно) Ручные обновления по умолчанию отключены для всех сущностей, управляемых через SCIM, включая возможность приглашать новых пользователей вручную. Это обеспечивает синхронизацию сущностей, управляемых через SCIM, с IdP, поэтому мы рекомендуем оставить этот параметр отключенным.
   - Однако, если вам необходимо вносить изменения вручную (например, изменять членство в группе, управляемой через SCIM), вы можете включить этот параметр, нажав **Allow manual updates** и подтвердив действие во всплывающем окне **Allow manual updates**. Подробнее об этом параметре см. в разделе [Что означает «Allow manual updates»?](/docs/platform/manage-access/scim-faq?version=1.12#what-does-allow-manual-updates-mean) в ответах на часто задаваемые вопросы о SCIM.
    <Lightbox src="/img/docs/dbt-platform/access-control/scim-manual-updates.png" width="70%" title="Включение ручных обновлений в настройках SCIM." />

## Следующие шаги

Настройте SCIM для своего поставщика удостоверений и при необходимости настройте управление лицензиями:

- **[Настройка SCIM с Okta](/docs/platform/manage-access/scim-okta)** &mdash; Создание учетных записей пользователей и групп, обновление профилей и [управление лицензиями](/docs/platform/manage-access/scim-manage-user-licenses) (только для Okta).
- **[Настройка SCIM с Entra ID](/docs/platform/manage-access/scim-entra-id)** &mdash; Создание учетных записей пользователей и групп, обновление профилей, а также назначение пользователям доступа к приложению SCIM.
- **[Часто задаваемые вопросы о SCIM и устранение неполадок](/docs/platform/manage-access/scim-faq)** &mdash; Распространенные вопросы и устранение неполадок при подготовке учетных записей через SCIM.
