Управляемые репозитории — отличный способ попробовать dbt без необходимости создавать новый репозиторий. Если у вас ещё нет репозитория <Constant name="git" /> для проекта dbt, вы можете доверить <Constant name="dbt" /> размещение репозитория и управление им. 

Если в будущем вы решите разместить этот репозиторий на другой платформе, вы сможете в любой момент экспортировать данные из <Constant name="dbt" />. Подробнее о том, как это сделать, см. в разделе [Переход с управляемого репозитория на самостоятельно размещённый репозиторий](/faqs/Git/managed-repo).

Если в будущем вы решите разместить этот репозиторий в другом месте, вы в любой момент сможете экспортировать данные из <Constant name="cloud" />. Подробнее о том, как это сделать, см. [Переход с управляемого репозитория на собственный](/faqs/Git/managed-repo).

:::info
dbt Labs не рекомендует использовать управляемый репозиторий в production‑окружении. Вы не сможете использовать возможности <Constant name="git" />, такие как pull request’ы, которые являются частью рекомендуемых лучших практик управления версиями.
:::

Чтобы настроить проект с управляемым репозиторием:

1. В разделе **Account settings** в <Constant name="dbt" /> выберите проект, для которого хотите настроить управляемый репозиторий. Если для проекта уже настроен репозиторий, необходимо изменить настройки репозитория и отключить существующий репозиторий.
2. Нажмите **Edit** для выбранного проекта.
3. В разделе Repository нажмите **Configure repository**.
4. Выберите **Managed**.
5. Введите имя репозитория. Например, "analytics" или "dbt-models".
6. Нажмите **Create**.

## Загрузка управляемого репозитория {#download-managed-repository}

Чтобы скачать копию управляемого репозитория из <Constant name="dbt" /> на локальный компьютер:

1. Используйте селектор **Project** в главном меню слева, чтобы перейти к проекту, использующему управляемый репозиторий.
2. Нажмите **Dashboard** в главном меню слева.
3. На панели мониторинга нажмите **Settings**.
4. Найдите поле **Repository** и нажмите ссылку на репозиторий.
5. Под **Deploy key** вы найдете опцию **Download repository**. Нажмите кнопку, чтобы скачать репозиторий. Если эта опция не отображается, вам либо не назначен [набор разрешений](/docs/platform/manage-access/enterprise-permissions#account-permissions) с доступом `write` к репозиториям Git, либо в вашем проекте нет управляемого репозитория.
