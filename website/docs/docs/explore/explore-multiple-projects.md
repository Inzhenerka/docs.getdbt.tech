# Обзор нескольких проектов

Просматривайте все проекты и публичные модели в своей учетной записи (в которых определены публичные модели), чтобы лучше понимать ресурсы, используемые в нескольких проектах, и способы их использования.

<ExplorerCourse />

Граф происхождения данных на уровне ресурсов проекта отображает межпроектные связи в DAG. Узлы, представляющие другой проект dbt, отмечены значком проекта слева от его имени.

На странице **Overview** проекта нажмите **View lineage** в правом верхнем углу, чтобы открыть граф происхождения данных на уровне ресурсов этого проекта. В этом графе:
- Просмотрите вышестоящий (родительский) проект, чтобы увидеть нижестоящие (дочерние) проекты, которые от него зависят.
- Выберите модель, чтобы увидеть в графе происхождения данных проекты, которые от неё зависят.
- Нажмите на вышестоящий (родительский) проект, чтобы на вкладке **Relationships** просмотреть другие проекты, которые на него ссылаются, и количество зависящих от него нижестоящих (дочерних) проектов.
  - Сюда входят все проекты, в файле `dependencies.yml` которых вышестоящий проект указан как зависимость, даже если прямой вызов `{{ ref() }}` отсутствует.
- Выберите узел проекта, связанный с публичной моделью, чтобы открыть его подробный граф происхождения данных, если у вас есть необходимые [разрешения](/docs/platform/manage-access/enterprise-permissions).

:::tip Косвенные зависимости
При просмотре графа происхождения данных проекта <Constant name="catalog" /> показывает только публичные модели, на которые есть _прямые_ [ссылки](/docs/mesh/govern/project-dependencies). [Косвенные зависимости](/faqs/Project_ref/indirectly-reference-upstream-model) не отображаются. Если модель, на которую ссылается ваш проект, зависит от другой вышестоящей публичной модели, эта модель второго уровня не появится в <Constant name="catalog" />, однако она будет отображаться в графе происхождения данных в [<Constant name="studio_ide" />](/docs/platform/studio-ide/develop-in-studio).
:::

При просмотре нижестоящего (дочернего) проекта, который импортирует публичные модели из вышестоящих (родительских) проектов и ссылается на них с помощью ref:
- Публичные модели отображаются на графе происхождения данных, и вы можете нажать на них, чтобы просмотреть подробную информацию о модели.
- При нажатии на модель открывается боковая панель с общей информацией о ней: конкретный проект <Constant name="dbt" />, в котором создаётся эта модель, описание, пакет и другие сведения.
- При двойном нажатии на модель из другого проекта открывается граф происхождения данных родительского проекта на уровне ресурсов, если у вас есть соответствующие разрешения.

## Исследование графа родословной на уровне проектов {#explore-the-project-level-lineage-graph}

При совместной работе над несколькими проектами вы можете взаимодействовать с DAG всеми способами, описанными в разделе [Изучение графа зависимостей проекта](/docs/explore/explore-projects#project-lineage). Вы также можете взаимодействовать с ним на уровне проекта и просматривать подробную информацию.

Если у вас есть разрешения для проекта в аккаунте, вы можете просматривать все публичные модели, используемые по всему аккаунту. Однако вы можете просматривать полные детали публичных моделей и частные модели только если у вас есть разрешения для конкретного проекта, где эти модели определены.

### Просмотр графа происхождения данных на уровне аккаунта

Чтобы просмотреть все проекты в аккаунте в виде графа происхождения данных или списка:

1. В **<Constant name="catalog" />** выберите свой проект на боковой панели.
2. Нажмите **Account lineage** в правом верхнем углу.

На графе происхождения данных на уровне аккаунта каждый проект отображается отдельным узлом с названием проекта и количеством предоставляемых им публичных моделей. Стрелки между узлами показывают зависимости проектов друг от друга. На верхней панели инструментов находятся строка поиска и переключатели между **List view** и представлением в виде графа происхождения данных. Элементы управления масштабом расположены в правом нижнем углу.

<Lightbox src="/img/docs/collaborate/dbt-explorer/account-level-lineage.gif" width="100%" title="Граф происхождения данных на уровне аккаунта, показывающий зависимости между проектами."/>

На графе происхождения данных на уровне аккаунта также можно:

- Нажать **List view**, чтобы перейти к таблице проектов и публичных моделей.
- Дважды щёлкнуть узел проекта, чтобы открыть граф происхождения данных на уровне ресурсов этого проекта.

### Изучение графа происхождения данных на уровне ресурсов проекта

На странице **Overview** проекта нажмите **View lineage**, чтобы открыть граф происхождения данных на уровне ресурсов этого проекта. В этом представлении отображаются:

- Источники, seed-файлы и модели текущего проекта, а также связи между ними.
- Нижестоящие проекты, ссылающиеся на публичные модели текущего проекта, в виде отдельных узлов проектов, соединённых пунктирными линиями.
- Строка поиска, **Lenses**, фильтр **Resource type**, условные обозначения типов ресурсов и элементы управления масштабом.

<Lightbox src="/img/docs/collaborate/dbt-explorer/multi-project-overview.gif" width="95%" title="Граф происхождения данных на уровне ресурсов с выбранной моделью и вкладкой Relationships."/>

При выборе модели справа открывается панель подробных сведений:

- Вкладка **General**: описание модели и поля метаданных, такие как **Project** и **Relation**.
- Вкладка **Columns**: название, тип данных и описание каждого столбца, а также результаты тестов столбцов, если тесты определены. В верхней части вкладки находится поле **Search for columns**.
- Вкладка **Relationships**: нижестоящие проекты, ссылающиеся на модель, перечисленные в разделе **Referenced by**.
