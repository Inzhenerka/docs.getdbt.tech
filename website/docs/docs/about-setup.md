dbt компилирует и выполняет ваш аналитический код на вашей платформе данных, позволяя вам и вашей команде работать с единственным источником правды для метрик, инсайтов и бизнес-определений. Существует два варианта развертывания dbt:

- **<Constant name="dbt_platform" />** (ранее dbt Cloud) запускает <Constant name="fusion_engine" /> или <Constant name="core" /> в управляемой среде (с одним или несколькими арендаторами) с интерфейсом в браузере. Интуитивно понятный пользовательский интерфейс помогает настроить различные компоненты. <Constant name="dbt" /> предоставляет готовые средства для запуска заданий по расписанию, CI/CD, размещения документации, мониторинга и оповещений. Также платформа предлагает интегрированную среду разработки (<Constant name="studio_ide" />) и позволяет разрабатывать проекты и выполнять команды dbt из локальной командной строки (CLI) или редактора кода.

- **Самостоятельно размещаемый dbt** — это бесплатный инструмент командной строки, который можно установить в локальной среде; взаимодействие с базами данных осуществляется через адаптеры.

Если вы не уверены, какое решение вам подходит, прочитайте наши статьи [Что такое dbt?](/docs/introduction) и [Возможности <Constant name="dbt" />](/docs/platform/about-platform/dbt-platform-features), чтобы определиться с выбором. Если у вас остались вопросы, [свяжитесь с нами](https://www.getdbt.com/contact/).

Чтобы начать настройку dbt, выберите подходящий для вас вариант.
