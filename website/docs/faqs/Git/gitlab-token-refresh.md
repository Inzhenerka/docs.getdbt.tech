Когда вы подключаете <Constant name="dbt" /> к репозиторию GitLab, GitLab автоматически создает в фоновом режиме [токен доступа к проекту](https://docs.gitlab.com/ee/user/project/settings/project_access_tokens.html) в вашем репозитории GitLab. Он используется для отправки статуса выполнения заданий CI обратно в GitLab через API <Constant name="dbt" />. 

По умолчанию имя токена доступа к проекту соответствует шаблону: `dbt token for GitLab project: <project_id>`. Если в вашем репозитории несколько токенов, найдите токен с именем, соответствующим этому шаблону, чтобы определить, какой из них используется <Constant name="dbt" />.

Если вы видите сообщение «Refresh token», не беспокойтесь &mdash; <Constant name="dbt" /> автоматически обновляет этот токен доступа к проекту, поэтому вам никогда не придется заменять его вручную.

Если ошибки обновления токена сохраняются, попробуйте отключить и снова подключить репозиторий в вашем проекте <Constant name="dbt" />, чтобы обновить токен.

Если у вас возникнут какие‑либо проблемы, пожалуйста, свяжитесь с командой поддержки по адресу support@getdbt.com — мы с радостью поможем!
