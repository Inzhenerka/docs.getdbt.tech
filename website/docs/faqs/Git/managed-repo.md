sidebar_label: 'Как запросить ZIP-файл вашего управляемого репозитория'
id: managed-repo
---

dbt Labs может передать вам управляемый репозиторий в его текущем состоянии в виде ZIP-файла, чтобы вы могли загрузить его на платформу хостинга Git. После этого вам останется лишь изменить [репозиторий в настройках проекта](/docs/platform/git/import-a-project-by-git-url), указав новый репозиторий.

Когда будете готовы это сделать, [свяжитесь с командой поддержки dbt Labs](mailto:support@getdbt.com) с вашим запросом и URL вашего управляемого репозитория, который вы можете найти, перейдя в настройки вашего проекта. Чтобы найти настройки проекта:

1. В <Constant name="dbt" /> нажмите на имя своей учетной записи в меню слева и выберите **Account settings**.
2. Нажмите **Projects**, затем выберите свой проект. 
3. В разделе **Repository** на странице сведений о проекте вы найдете URL своего управляемого репозитория.
