Если вы столкнулись с проблемой в Jinja, может быть сложно понять, где искать дополнительную информацию. Мы рекомендуем проверять (в порядке приоритета):

1. [Документация Jinja для разработчиков шаблонов](https://jinja.palletsprojects.com/page/templates/): Это лучший справочник по большинству возможностей Jinja, которые вы будете использовать.
2. [Поддержка Jinja по типам файлов](/reference/jinja-file-support): Здесь указано, какие типы файлов поддерживают выражения Jinja, встроенные функции и пользовательские макросы.
3. [Наш справочник по функциям Jinja](/reference/dbt-jinja-functions-context-variables): Здесь описаны все дополнительные возможности, которые мы добавили в Jinja в dbt.
4. [Документация Agate по таблицам](https://agate.readthedocs.io/page/api/table.html): Если вы работаете с результатом запроса, dbt вернёт его вам в виде таблицы agate. Это означает, что методы, которые вы вызываете для <Term id="table" />, относятся к библиотеке Agate, а не к Jinja или dbt.
