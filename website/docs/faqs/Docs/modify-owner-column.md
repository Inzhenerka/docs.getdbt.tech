---
title: Как заполнить столбец owner в сгенерированной документации?
description: "Изменение столбца owner"
sidebar_label: 'Можно ли заполнить столбец owner в документации?'

---

Вы не можете изменить столбец `owner` в сгенерированной документации.
 
dbt получает поле `owner` в `dbt-docs` из метаданных базы данных ([catalog.json](/reference/artifacts/catalog-json)), то есть это владелец (`owner`) таблицы в базе данных. За исключением [exposures](/docs/build/exposures), dbt не получает это значение из поля `owner`, заданного в dbt.
 
Обычно пользователю базы данных, от имени которого работает dbt, принадлежат таблицы, созданные в базе данных. Исходные таблицы обычно принадлежат сервису, который отвечает за получение или загрузку данных.
 
Если вы зададите `meta.owner`, это поле появится в разделе **meta** (со значением из dbt), но по-прежнему не будет отображаться в поле `owner` верхнего уровня.

## Пример

В следующем примере показана модель с `meta.owner`, благодаря чему это поле отображается в разделе **meta** документации. Замените `DATA_TEAM_EMAIL` собственным значением.

<File name='models/stg_orders.yml'>
```yaml
models:
  - name: stg_orders
    description: "Промежуточная таблица событий заказов."
    config:
      meta:
        owner: "DATA_TEAM_EMAIL"
    columns:
      - name: order_id
        description: "Первичный ключ заказов."
      - name: order_date
        description: "Дата оформления заказа."
```
</File>
