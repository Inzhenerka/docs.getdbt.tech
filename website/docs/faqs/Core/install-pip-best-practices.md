## Рекомендации

Управлять локальными окружениями Python бывает непросто! Эти рекомендации помогут вам сделать установку <Constant name="core" /> с помощью `pip` более надёжной. 

| Рекомендация | Что делать | Почему это важно |
|---------------|----------------|----------------|
| [Устанавливайте <Constant name="core" /> вместе с адаптером](/docs/local/install-dbt?version=1#install-your-adapter) и следите за совместимостью версий | Используйте команду: `python -m pip install dbt-ADAPTER_NAME` <br /><br /> (Например, `python -m pip install dbt-snowflake`) <br /><br /> Подбирайте версии адаптеров, совместимые с вашей версией <Constant name="core" /> <br /><br /> | Обеспечивает полноценную, совместимую и готовую к работе установку dbt <br /><br /> <br /><br /> Предотвращает ошибки во время выполнения и проблемы совместимости адаптеров |
| Для инструментов, которым не требуется подключение к хранилищу данных, устанавливайте v1 без адаптера | `python -m pip install dbt-core` | Позволяет избежать лишних компонентов, делает окружение предсказуемым и упрощает его обслуживание|
| Используйте [виртуальные окружения](/faqs/Core/install-pip-best-practices.md#using-virtual-environments) | Устанавливайте dbt в изолированном окружении (например, `venv`, `pipenv`, `poetry`) | Позволяет избежать конфликтов зависимостей |
| Повторно активируйте виртуальное окружение в каждом сеансе | Активируйте виртуальное окружение в начале каждого нового сеанса перед установкой зависимостей или выполнением команд dbt | Обеспечивает предсказуемость, изолированность и воспроизводимость вашего окружения dbt |
| [Создайте проект](/reference/commands/init) | Используйте команду `dbt init`, чтобы создать и инициализировать свой первый проект | Создаёт стандартный проект dbt и позволяет проверить установку |
| Убедитесь, что у вас установлены последние версии `pip`, `wheel` и `setuptools` | Перед установкой dbt обновите инструменты управления пакетами Python:<br /><br />`python -m pip install --upgrade pip wheel setuptools` | Помогает сделать установку dbt более гладкой и предсказуемой |

<br />

Обратите внимание: адаптеры dbt и <Constant name="core" /> имеют независимую нумерацию версий, чтобы нам было проще поддерживать и независимо развивать адаптеры в дальнейшем.

### Использование виртуальных окружений {#using-virtual-environments}

Мы рекомендуем использовать [виртуальные окружения](https://docs.python-guide.org/dev/virtualenvs/) для изоляции модулей `pip`. Вот пример настройки:

```shell

python3 -m venv dbt-env				# создание окружения
source dbt-env/bin/activate			# активация окружения для Mac и Linux
dbt-env\Scripts\activate			# активация окружения для Windows
```

Если вы устанавливаете `dbt` в виртуальном окружении, вам нужно будет повторно активировать это же виртуальное окружение каждый раз, когда вы создаете новое окно или сессию оболочки.

*Совет:* Вы можете создать псевдоним для команды `source` в вашем `$HOME/.bashrc`, `$HOME/.zshrc` или любом другом rc-файле, который использует ваша оболочка. Например, вы можете добавить команду вроде `alias env_dbt='source <PATH_TO_VIRTUAL_ENV_CONFIG>/bin/activate'`, заменив `<PATH_TO_VIRTUAL_ENV_CONFIG>` на путь к вашей конфигурации виртуального окружения.

### Использование последних версий {#using-the-latest-versions}

Установки dbt тестируются с использованием последних версий `pip` и `setuptools`. Новые версии имеют улучшенное поведение при разрешении зависимостей, а также значительно более быстрое время установки благодаря использованию предварительно скомпилированных "колес" (wheels), когда они доступны для вашей операционной системы.

Перед установкой dbt убедитесь, что у вас установлены последние версии:

```shell

python -m pip install --upgrade pip wheel setuptools

```
