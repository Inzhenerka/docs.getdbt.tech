<Constant name="dbt" /> поддерживает [подключения](/docs/platform/connect-data-platform/about-connections#connection-management), доступные всем пользователям <Constant name="dbt" />. Подключения позволяют использовать разные подключения к платформам данных для каждой среды, устраняя необходимость дублировать проекты. В рамках одного проекта можно использовать несколько подключений только к хранилищам одного типа. Подключения можно повторно использовать в разных проектах и средах.

В dbt v1 можно поддерживать отдельные производственные среды и среды разработки с помощью [`targets`](/reference/dbt-jinja-functions/target) в [профиле](/docs/local/profiles.yml). Пользователи dbt v1 могут определять разные целевые конфигурации (targets) в файле profiles.yml, что позволяет настроить в одном профиле целевые конфигурации для разных хранилищ данных.
