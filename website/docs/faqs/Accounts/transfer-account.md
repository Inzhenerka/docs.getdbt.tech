---

Вы можете передать свои [права доступа](/docs/platform/manage-access/about-user-access) в <Constant name="dbt" /> другому пользователю, выполнив приведённые ниже действия в зависимости от тарифного плана вашей учётной записи <Constant name="dbt" />:

| План аккаунта | Шаги | 
| ------ | ---------- | 
| **Developer** | Вы можете передать права владельца, изменив адрес электронной почты непосредственно на странице своего профиля <Constant name="dbt" />. Чтобы открыть эту страницу, используйте следующий URL, заменив `YOUR_ACCESS_URL` на [соответствующий URL доступа](/docs/platform/about-platform/access-regions-ip-addresses) для вашего региона и тарифного плана: `https://YOUR_ACCESS_URL/settings/profile`. Прежде чем делать это, обязательно отвяжите свой профиль GitHub. Адрес электронной почты нового владельца аккаунта не должен быть связан с другим аккаунтом <Constant name="dbt" />.|
| **Starter** | Действующие администраторы аккаунта, имеющие к нему доступ, могут добавлять пользователей в группу владельцев или удалять их из этой группы. | 
| **Enterprise или Enterprise+** | Администраторы аккаунта могут добавлять пользователей в группу с разрешениями Account Admin или удалять их из этой группы. | 
| **Если все владельцы аккаунта ушли из компании** | Если владелец аккаунта покинул вашу организацию, вам потребуется обратиться в _ваш_ ИТ-отдел, чтобы настроить пересылку входящих писем новому владельцу аккаунта. После того как ИТ-отдел настроит пересылку, вы сможете запросить сброс пароля пользователя. После входа в систему вы сможете изменить адрес электронной почты на странице профиля, заменив `YOUR_ACCESS_URL` на [соответствующий URL доступа](/docs/platform/about-platform/access-regions-ip-addresses) для вашего региона и тарифного плана:  `https://YOUR_ACCESS_URL/settings/profile`. |

Когда вы вносите изменения в владельца аккаунта и адрес электронной почты:

- Новый адрес электронной почты _обязательно_ должен пройти нашу процедуру подтверждения.
- При необходимости вы можете обновить адреса электронной почты для выставления счетов или [настройки уведомлений](/docs/deploy/job-notifications), чтобы отразить смену владельца аккаунта.
- При передаче прав владельца аккаунта обязательно [отвяжите](/faqs/Accounts/git-account-in-use) свой аккаунт GitHub в <Constant name="dbt" />. Это необходимо, поскольку аккаунт <Constant name="git" /> можно связать только с одним аккаунтом пользователя <Constant name="dbt" />.
