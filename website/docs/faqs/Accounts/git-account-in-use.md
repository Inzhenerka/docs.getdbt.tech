description: "Что делать, если вы получаете ошибку использования учетной записи Git"

---

Если при попытке подключить GitHub на странице профиля вы получаете ошибку «Account in use», это связано с тем, что интеграция с <Constant name="git" /> работает по принципу «один к одному»: вашу учетную запись <Constant name="git" /> можно связать только с одной учетной записью пользователя <Constant name="dbt" />.

Вот несколько шагов, которые помогут вам решить эту проблему:

* Войдите в учетную запись <Constant name="dbt" />, связанную с вашей учетной записью <Constant name="git" />. Перейдите в свой профиль пользователя и нажмите Integrations, чтобы удалить связь.

Если вы не помните, с какой учетной записью <Constant name="dbt" /> настроена интеграция, напишите в службу поддержки dbt по адресу support@getdbt.com, и мы постараемся помочь вам отключить эту интеграцию.
