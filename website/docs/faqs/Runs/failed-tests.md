Чтобы отладить неудачный тест, найдите SQL, который выполнил dbt, следующим образом:

* <Constant name="dbt" />:
  * В результатах тестирования нажмите на тест, завершившийся с ошибкой, а затем выберите «Details».

* <Constant name="core" />:
  * Откройте файл по пути, указанному в сообщении об ошибке.
  * Перейдите в каталог `target/compiled/schema_tests`, где находятся все скомпилированные SQL-запросы тестов.

Скопируйте SQL-код в редактор запросов (в <Constant name="dbt" /> его можно вставить в новый `Statement`) и выполните запрос, чтобы найти записи, не прошедшие тест.

Скопируйте SQL в редактор запросов (в <Constant name="cloud" /> вы можете вставить его в новый `Statement`) и выполните запрос, чтобы найти записи, которые не прошли тест.
