Да!

* **Руководство по быстрому старту:** Вы можете создать собственный пример проекта dbt, следуя [руководству по быстрому старту](/docs/get-started-dbt)
* **Jaffle Shop:** Демонстрационный проект (тесно связанный с учебным руководством) для вымышленного интернет-магазина. Инструкции по клонированию см. в разделе [Клонирование примера проекта Jaffle Shop](/guides/clone-jaffle-shop). Также на GitHub доступны [основной исходный код](https://github.com/dbt-labs/jaffle-shop) и [исходный код с использованием DuckDB](https://github.com/dbt-labs/jaffle_shop_duckdb).
* **GitLab:** Внутренний проект dbt компании GitLab имеет открытый исходный код и служит отличным примером масштабного использования dbt ([исходный код](https://gitlab.com/gitlab-com/content-sites/handbook/blob/main/content/handbook/enterprise-data/platform/dbt-guide.md))
* **dummy-dbt:** Контейнеризированный проект dbt, который наполняет базу данных Sakila в Postgres и создает seed-данные, модели, снимки и тесты dbt. Проект можно использовать для тестирования и экспериментов ([исходный код](https://github.com/gmyrianthous/dbt-dummy))
* **Google Analytics 4:** Демонстрационный проект, который преобразует данные, экспортированные из Google Analytics 4 в BigQuery, в различные модели ([исходный код](https://github.com/stacktonic-com/stacktonic-dbt-example-project), [документация](https://stacktonic.com/article/google-analytics-big-query-and-dbt-a-dbt-example-project))
* **Make Open Data:**  Готовый к промышленной эксплуатации ELT-проект с тестами, документацией и CI/CD (GHA), посвященный открытым данным Франции (жилье, демография, география и т. д.). Его можно использовать для обучения работе с большими объемами неоднозначных данных. Приветствуется участие в развитии проекта ([исходный код](https://github.com/make-open-data/make-open-data).

Если у вас есть пример проекта, который вы хотите добавить в этот список, предложите правку, нажав **Edit this page** ниже.
