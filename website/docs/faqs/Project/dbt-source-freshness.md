---

---
Да!

<VersionBlock firstVersion="2.0">

Команда [`dbt freshness`](/reference/commands/freshness) определяет, насколько недавно были загружены данные, и сообщает статус успеха, предупреждения или ошибки для каждого источника или модели на основе заданных порогов `warn_after` и `error_after`.

dbt записывает результаты проверки свежести моделей и источников в `target/freshness.json`. Если проверка включает источники, dbt также записывает `target/sources.json` для обратной совместимости.

</VersionBlock>

<VersionBlock lastVersion="1.99">

Команда `dbt source freshness` выводит статус успеха, предупреждения или ошибки для каждой таблицы (<Term id="table" />), выбранной для снимка свежести.

Кроме того, dbt по умолчанию записывает результаты проверки актуальности в файл в каталоге `target/` под названием `sources.json`. Вы также можете изменить это место назначения, используя флаг `-o` в команде `dbt source freshness`.

</VersionBlock>

После включения проверки свежести источников в задании настройте [артефакты](/docs/deploy/artifacts) на странице **Project Details**. Чтобы открыть эту страницу, выберите имя своей учетной записи в левом боковом меню <Constant name="dbt" /> и нажмите **Account settings**. Текущий статус свежести источников можно посмотреть, нажав **View Sources** на странице задания.
