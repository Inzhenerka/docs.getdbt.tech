Если вашего репозитория нет в списке, убедитесь, что:
- Ваш репозиторий находится в группе GitLab, к которой у вас есть доступ. <Constant name="dbt" /> не читает репозитории, принадлежащие пользователю.

Если вы видите свой репозиторий в списке, но не можете успешно его импортировать, дважды проверьте, что:
- Вы являетесь мейнтейнером этого репозитория. Только пользователи с правами мейнтейнера могут настраивать подключения к репозиторию.

Если вы импортировали репозиторий с помощью встроенной интеграции <Constant name="dbt" /> с GitLab, вы сможете проверить, используется ли `deploy_token` для клонирования. Если для клонирования используется SSH-ключ, это означает, что репозиторий был подключен не через встроенную интеграцию с GitLab, а с помощью стандартной опции клонирования git. Чтобы получить описанные выше преимущества, необходимо повторно подключить репозиторий.
