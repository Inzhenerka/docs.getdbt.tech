---
title: Я получаю ошибку `Failed ALPN` при попытке подключения к dbt Semantic Layer
description: "Чтобы устранить ошибку 'Failed ALPN' в dbt Semantic Layer, создайте исключение для SSL‑перехвата для домена dbt."
sidebar_label: 'Используйте SSL‑исключение для устранения ошибки `Failed ALPN`'
---

Если при попытке подключить dbt Semantic Layer к различным [инструментам интеграции данных](/docs/platform-integrations/avail-sl-integrations) (например, Tableau, DBeaver, Datagrip, ADBC или JDBC) вы получаете ошибку `Failed ALPN`, обычно это происходит при подключении с компьютера, находящегося за корпоративным VPN или прокси-сервером (например, Zscaler или Check Point).

Первопричина обычно заключается в том, что прокси вмешивается в TLS‑рукопожатие, поскольку <Constant name="semantic_layer" /> использует gRPC/HTTP2 для подключения. Чтобы решить эту проблему:

- Если ваш прокси-сервер поддерживает gRPC/HTTP2, но не настроен на использование ALPN, измените его настройки, чтобы разрешить ALPN. Или создайте исключение для домена <Constant name="dbt" />.
- Если ваш прокси-сервер не поддерживает gRPC/HTTP2, добавьте в его настройках исключение из перехвата SSL для домена <Constant name="dbt" />

Это должно помочь успешно установить соединение без ошибки Failed ALPN.
