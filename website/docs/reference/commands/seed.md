Команда `dbt seed` загружает статические CSV-файлы из каталогов проекта, указанных в `seed-paths`, в ваше <Term id="data-warehouse" /> в виде таблиц. Используйте seeds для небольших справочных наборов данных под контролем версий, которые нужно хранить вместе с проектом, например кодов стран, соответствий регионов или списка категорий, определённых бизнесом.

После загрузки seeds вы можете ссылаться на полученные таблицы в последующих моделях и повторно запускать `dbt seed` при изменении CSV-файлов.

Seeds настраиваются в файле `dbt_project.yml`, где можно задать такие параметры, как каталоги с seed-файлами и правила интерпретации столбцов. Затем команда `dbt seed` загружает эти CSV-файлы в ваше хранилище данных, чтобы вы могли ссылаться на них в последующих моделях.

## Обзор

В этом разделе рассматриваются типичные результаты выполнения `dbt seed` (артефакты и вывод CLI), а также параметры, которые могут пригодиться при запуске seeds.

Используйте артефакты, чтобы изучить ход выполнения или выявить причины проблем:
- Артефакты: запуск `dbt seed` создаёт артефакты выполнения dbt, включая `run_results.json` для выполненных seeds. Подробнее о содержимом этого файла и его интерпретации см. в разделе [JSON-файл результатов выполнения](/reference/artifacts/run-results-json).<br />

Используйте выбор ресурсов, чтобы запускать только часть seeds:
- Выбор ресурсов: подробнее о расширенных шаблонах выбора (тегах, путях, операторах графа и других возможностях) см. в разделе [Обзор синтаксиса](/reference/node-selection/syntax).<br />

Используйте глобальные флаги для управления поведением команды, журналированием и параметрами выполнения:
- Флаги: `dbt seed` поддерживает глобальные флаги dbt. Полный список см. в разделах [Параметры командной строки](/reference/global-configs/command-line-options) и [Доступные флаги](/reference/global-configs/about-global-configs#available-flags).

## Выбор seeds

Вы можете запускать отдельные seeds с помощью флага `--select` при выполнении команды `dbt seed`. Например:

### Выбор seed-файлов для выполнения {#selecting-seeds-to-run}

```shell
dbt seed --select "country_codes"
Found 2 models, 3 tests, 0 archives, 0 analyses, 53 macros, 0 operations, 2 seed files

14:46:15 | Concurrency: 1 threads (target='dev')
14:46:15 |
14:46:15 | 1 of 1 START seed file analytics.country_codes........................... [RUN]
14:46:15 | 1 of 1 OK loaded seed file analytics.country_codes....................... [INSERT 3 in 0.01s]
14:46:16 |
14:46:16 | Finished running 1 seed in 0.14s.
```

Примеры распространённых вариантов вызова `dbt seed`:

```shell
# Run all seeds
dbt seed

# Run one seed
dbt seed --select "country_codes"

# Rebuild selected seeds from scratch
dbt seed --select "country_codes state_codes" --full-refresh
```

## Флаг --full-refresh

Используйте `--full-refresh`, чтобы принудительно выполнить полную загрузку данных seed (вместо инкрементального обновления), когда нужно пересоздать таблицы seed с нуля. Это полезно в следующих случаях:

- Вы хотите принудительно выполнить повторную загрузку данных seed с очисткой:

  ```shell
  dbt seed --full-refresh
  ```

- Вы изменили структуру seed (например, имена или типы столбцов):

  ```shell
  dbt seed --select "country_codes" --full-refresh
  ```

- Вам нужно обеспечить одинаковое поведение в разных средах после изменения seed:

  ```shell
  dbt seed --select "country_codes state_codes" --full-refresh
  ```

Информацию о настройке seed (например, о типах столбцов и использовании кавычек) см. в разделе [Конфигурации seed](/reference/seed-configs).

## Флаг --empty

Используйте `--empty`, чтобы создать таблицы seed с нужной схемой, но без загрузки данных. dbt определяет имена и типы столбцов по CSV-файлу, но не вставляет ни одной строки. Это полезно в средах разработки или CI, где для зависимых моделей и модульных тестов необходима структура таблиц, но загрузка полных наборов данных создаёт лишнюю нагрузку. Например:

- Создайте таблицы seed без данных, чтобы зависимые модели и модульные тесты могли компилироваться и выполняться:

  ```shell
  dbt seed --empty
  ```

- Выберите конкретный seed, если вам нужна структура только одной таблицы:

  ```shell
  dbt seed --select "country_codes" --empty
  ```

Дополнительную информацию см. в разделе [Флаг empty](/docs/build/empty-flag).

</VersionBlock>
