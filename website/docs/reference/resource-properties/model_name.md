## Определение
Имя модели, для которой вы объявляете свойства. Должно совпадать с _именем файла_ модели &mdash; с учётом регистра. Любое несовпадение регистра может помешать dbt корректно применить конфигурации и повлиять на метаданные в <Constant name="catalog" />.

## Значение по умолчанию {#default}

Это **обязательное свойство**, значение по умолчанию отсутствует.
