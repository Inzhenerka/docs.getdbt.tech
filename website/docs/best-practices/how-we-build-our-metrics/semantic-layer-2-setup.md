## Начало работы {#getting-started}

Существует два варианта разработки проекта dbt, включая <Constant name="semantic_layer" />:

- [<Constant name="platform_cli" />](/docs/platform/dbt-cli-installation) &mdash; Команды MetricFlow встроены в <Constant name="platform_cli" /> и доступны через подкоманду `dbt sl`. На данный момент это самый простой и функционально полный способ разработки кода для <Constant name="semantic_layer" />. Вы можете использовать любой удобный редактор и запускать команды из терминала.

- [<Constant name="studio_ide" />](/docs/platform/studio-ide/develop-in-studio) &mdash; Вы можете создавать семантические модели и метрики в <Constant name="studio_ide" />.

## Основные команды {#basic-commands}

- 🔍 Менее распространённая команда, которая пригодится при работе с <Constant name="semantic_layer" />, — `dbt parse`. Она разбирает ваш проект и создаёт **семантический манифест** — представление смысловых связей, описанных в проекте. Этот манифест загружается в <Constant name="dbt" /> и используется для выполнения команд `dbt sl` в процессе разработки. Этот файл предоставляет MetricFlow **снимок текущего состояния, на основе которого генерируются запросы**.
- 🧰 `dbt sl query` — ещё один ваш незаменимый помощник: эта команда выполняет запрос к вашему семантическому слою и возвращает выборку результатов. Она отлично подходит для проверки семантических моделей и метрик по мере их создания. Например, если вы создаёте модель выручки, можно выполнить `dbt sl query --metrics revenue --group-by metric_time__month`, чтобы убедиться, что месячная выручка рассчитывается правильно.
- 📝 Наконец, `dbt sl list dimensions --metrics [metric name]` выводит список всех измерений, доступных для заданной метрики. Это полезно, чтобы проверять, что по мере разработки вы расширяете набор доступных измерений. С помощью `dbt sl list` можно также просматривать другие элементы вашего <Constant name="semantic_layer" />. Чтобы увидеть полный список доступных параметров, выполните `dbt sl list --help`.

Для получения дополнительной информации о доступных командах обратитесь к справочнику [команд MetricFlow](/docs/build/metricflow-commands) или используйте `dbt sl --help` и `dbt sl [subcommand] --help` в командной строке. Если вам нужно сначала настроить проект dbt, ознакомьтесь с [руководствами по быстрому старту](/docs/get-started-dbt).
